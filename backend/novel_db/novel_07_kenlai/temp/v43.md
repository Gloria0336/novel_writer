## 一、世界基礎

- 架空現代修仙世界。
- **歷史縱深**：有清楚文字記錄的歷史達數十萬年；可被證實的真實歷史達百萬年。
- 因歷史久遠，世上留有無數傳承、秘境、遺跡。
- **科技**：科技樹以靈氣為起點，而非電力。無法修煉的普通人同樣能使用靈氣科技產品。

### 1.1 命名規則
- **人名與組織名**可帶有現實語感，視為此世界的原生名稱（偉恩、荒阪、亞特蘭蒂斯皆沿用）。
- **地名應原創**，且**依區域文化分別採用不同語感**：**正道區漢字、聯邦區西式、帝國區西式（與聯邦同調）**。
- **修訂（v16）**：**漢字地名可帶現實語感**，視為此世界的原生名稱（如樓蘭城）。
- 地名不作一次性建立，於後續建構過程中**由你逐步提供**。Claude 不代為命名。

## 二、戰力體系

兩條路線並行，**無高低之分**。修煉方式五花八門、各有道統，但境界劃分全球統一（各體系內部統一）。

### 修仙（11 境）
練氣 → 築基 → 觀海 → 龍門 → 金丹 → 元嬰 → 玉璞 → 仙人 → 化神 → 飛昇 → 大帝

### 煉體（11 境，純粹武夫，不修鍊靈氣）
泥柸 → 木胎 → 水銀 → 英魂 → 雄魄 → 武膽 → 金身 → 羽化 → 山巔 → 止境 → 武神

### 2.1 跨體系換算
- 兩者同為 11 境**純屬巧合**。
- **兩體系無法換算**，世界上不存在統一的實力刻度。

### 2.2 修煉本質的差異
- **練氣**：以天地靈氣滋養全身，**以整個世界昇華肉體**。
- **煉體**：追求破與立，不斷激發肉體潛能。信條為「**大丈夫立於天地，當以一拳立之**」。可獲得匹敵天地之力，但**仍無法超脫天地**。

> **界定**：煉體「不依賴天地」指的是**悟道機制**不依賴，並非對環境傷害免疫。極端靈氣環境對煉體者同樣有害。

### 2.3 壽命的差異
| 體系 | 壽元 |
|---|---|
| 練氣 | 數百至上千年為常態 |
| 練氣・飛昇境 | 可達數千年 |
| 練氣・悟道者 | **執掌一道，可超脫壽元限制**（世界普遍常識，見 3.9） |
| 煉體 | 可延年益壽，但**有明確上限**。歷史已知最長壽的武神僅一千歲 |

### 2.4 頂點的戰力對比
- **武神與大帝之間並無絕對高下之分。**
- **大帝**：執掌一道，以**神明之姿俯瞰眾生**。
- **武神**：以**一己之力立於天地**，佛擋殺佛、神擋殺神。

> **適用範圍（v11 修正）**：「武神與大帝並無絕對高下」**僅適用於以生死戰鬥成道的武神**。見 3.5。

### 2.5 練氣的三道門檻（v12 新增）

| 門檻 | 名稱 | 意義 |
|---|---|---|
| 龍門 → 金丹 | **躍龍門** | 從**主動吸納**天地靈氣，轉為**擁有金丹、可被動吸收**靈氣的轉折點 |
| 玉璞 → 仙人 | **羽化成仙** | 靈氣在體內**自成小世界**，此後可稱**仙氣**而非靈氣 |
| 飛昇 → 大帝 | **證道** | 悟道成帝，**執掌世界一道法則** |

> **命名界定（v17，原待裁決項目 25 結案）**：「羽化成仙」與煉體第八境「羽化」**同形而不同源**，兩者皆為各自體系內的正式名稱，互不相關。

## 三、悟道與頂點

### 3.1 道的法則
- **世界萬物皆有道。只有悟道，才能成就大帝。**
- **每一條道的終點，只能有一人。**
- 悟道**並非突破飛昇後才開始**，而是與修士的一生相關——**你是什麼人，決定了你將來可能悟什麼道。**

### 3.2 自覺與檢測
- 修士能否得知自己可能悟什麼道，**因人而異**：有人早有自覺，有人至死不明。
- **不存在外部檢測手段，也沒有任何機構能夠判定。**

### 3.3 席位的佔據與釋出
- 若某條道已被他人佔據，後來者**可修煉至飛昇圓滿，但永遠跨不過最後那道門檻**。
- **持有者身死道消，該道即釋出**，他人可重走。
- **例外：天絕大帝**。其靈魂尚存，故其道至今仍被佔據。
> **判準（v12 確認）**：道是否被佔據，**以靈魂是否尚存為準**，與道身無關。
>
> **天絕的本體（v13 確認）**：其現存的**靈魂碎片即是他的本體**。

### 3.4 奪道（v13 改寫）

**掌道的原理**
- **道身並非佔據一道的依據。**
- 大帝之所以能佔據一道，是因為**道身與本體的雙向作用**。
- **只要有一邊斷掉，就會失去對道的掌握。**

**兩條路**

| # | 方式 | 說明 |
|---|---|---|
| 1 | **殺死本體** | 斷掉雙向作用的其中一端 |
| 2 | **與道身論道** | 修煉出道身，或**設法前往世界之外**，與大帝的道身論道成功。**論道成功者直接取得該道。** |

> 前提是必須先查出攔路者是誰，而道不可外部檢測。
>
> **現況（v41 補完，原項目 26 結案）**：道門已毀，但**仍有別的方式前往世界之外**。
>
> 該方式**可觀測、可互動，但無法論道**——因此**不能用於奪道，也不能用於證道**。它的用途不在權力，在**認識**。13.8 已定世界之外是法則集合體、宇宙運轉的底層邏輯，而這條路做的事情就是**讓人看見底層**。
>
> 世上**有傳說，但無人證實**。

### 3.5 煉體的頂點（v11 改寫，原待裁決項目 4 結案）

**武道**
- 武神**同樣需要悟道**，但機制不同。
- **全體煉體者所悟的都是同一條道——武道**，只是**每個人的悟法不同**。
- **武道是一種特殊的道，不會有佔用的問題。**
- 因此**武神不佔據任何道**，且歷史上**曾同時存在多名武神**。

> 武道是 3.1「每一條道的終點只能有一人」的**唯一例外**。

**成道路徑（二分）**

| 路徑 | 性質 |
|---|---|
| **生死戰鬥** | 悟武道**最有效率**的方式，**失敗率極高** |
| **其他方式** | **耗時極長**，受煉體壽元上限制約；且**水分極高，實際戰力甚至不及普通止境** |

**其他**
- **每名武神的能力表現各不相同。**
- **世人的承認**：以其他方式成就者，境界確為武神，但**歷史上都不被世人承認**。

### 3.6 山巔人

- 「山巔人」是**實力頂層之人彼此之間的口語化自稱**，非正式名詞、無官方定義。
- 所指對象為**三千年來累積的飛昇圓滿者**（不含煉體體系）。
- **有一定數量**，多已隱世不出：或成為各方勢力的幕後，或單純隱居。
- **他們正是知曉「部分」真相的人**。

> **命名界定（v7 裁決，原待裁決項目 1 結案）**：本詞與煉體第九境「山巔」**無關**。「山巔」作為煉體第九境是**全球統一的正式名稱**；「山巔人」僅為口語自稱。兩者同形而不同源。
>
> 「山巔人」一詞在圈外的流通程度**暫置**。

### 3.8 世界之外與道門（v12 新增）

- 這個世界之外**確實存在「世界之外」**：一種**法則集合體**，代表**宇宙運轉的底層邏輯**。
- **證道的過程**：修煉出**道身**，前往世界之外，在那裡**證明自己的道**並**取得執掌大權**。
- **證道的性質是一場交易**：道身前往世界之外，等同**以畢生所學向世界換取一個大帝名額**，執掌一道。
- 前往世界之外**有一條明確的路徑**（非物理上存在的實體），稱為「**道門**」。
- **三千年前的大戰在過程中摧毀了道門**，此後所有人**失去了那條路**。

> **界定**：**道門即 6.4 所稱「被破壞的條件」，兩者同一。**
>
> **普及度**：「世界之外」與「道門」**僅高階修士知曉**。

### 3.9 大帝的消散（世界真相，v12 新增）

- 前往證道的是**道身**，**本體仍留在世上**。
- 成功證道後，**道身會留在世界之外**。**道身即大帝的證道精華。**
- **隱藏的事實**：證道之後，大帝**無一例外會緩慢消散於世間**。
- **成因**：**本體沒有道身，就像失去滋養的大樹，會緩慢凋零。**
- **凋零之時，道身會融入該道，成為養料。**
- 此過程**極其漫長，甚至可持續萬年**。**消散前實力不變。**
- 這個真相對大帝本身是**不可名狀、不可言說的事實**，因此**無法向下傳承**。
- **世人只知**：某人證道後慢慢淡出人間，**從此不知去向**。

> 「執掌一道可超脫壽元限制」是**世界普遍常識**；「緩慢消散」是**世界真相**。

### 3.7 現存的武神

- **現世仍有武神在世，僅一人。約兩百多年前成道**，未親歷三千年前的大戰。
- **姓名：裴思涵。女性。**
- **出身**：**龍隱城**。該城為**門派附屬城市，並非直屬於任一門派**（所在陸地待定）。
- **成道路徑**：**以生死戰鬥成道。**
- **舊稱號**：成道前世稱「**神龍大俠**」。成為武神後此號鮮少再被提起。**此稱號與其出身龍隱城有意關聯。**
- **現稱**：世人多稱「**武神**」「**裴武神**」，或直呼「**裴思涵**」。
- **不介入世俗事務**——指不介入勢力鬥爭，非不與人來往。
- **身分可查，至今仍是知名人物**，只是神龍見首不見尾。
- **現身樣態**：市井現身、與常人無異、不表明身分；僅在特定事件或場合；數十年一次；不引發各方警覺。
- **現身理由**：**純粹個人因素，與世局無關。**

## 四、世界地理

### 4.1 大陸格局
- **大致如地球**：數塊大陸與大洋，各勢力分踞。
- 地形近似真實地球，但**區域劃分與名稱全然不同**，現實地名不可沿用。

**已命名的陸塊與海域（v15）**

| 名稱 | 內容 |
|---|---|
| **大道洲** | 正道聯盟所在。大戰後雖分為兩塊，**仍統稱大道洲**，底下分為**北大道洲**與**南大道洲** |
| **絕天海** | 兩塊陸地之間新生的海域。**因三千年前那場大戰而得名** |
| **歐姆尼亞洲**（簡稱**歐洲**） | 波希特米亞聯邦所在的大陸 |
| **亞特蘭蒂斯洲** | 帝國**所有領土的集合** |
| **波塞頓半島** | 亞特蘭蒂斯**皇都所在的半島** |
| **蓬萊群島** | 大道洲**東北部外海**的群島，面積約與日本相當。**無主的自由貿易區**，魚龍混雜的自由城市；**荒阪集團的大型總部之一即在島上** |
| **福爾摩沙島** | 位於**蓬萊群島南端、大陸東側**的小島，面積約與台灣相當。詳見 4.7 |

| **華盛頓市** | **歐姆尼亞洲西岸**，**波希特米亞聯邦首都**。得名自國父**恩菲・華盛頓** |

### 4.2 勢力分布

| 區域 | 歸屬 |
|---|---|
| **大道洲**（北大道洲、南大道洲） | 正道聯盟 |
| **歐姆尼亞洲**，與大道洲**隔海相望** | 波希特米亞聯邦 |
| **亞特蘭蒂斯洲**（皇都位於**波塞頓半島**） | 亞特蘭蒂斯帝國 |
| **高譚市**（歐姆尼亞洲東岸） | **偉恩企業核心** |
| （無實質核心） | **荒阪集團**。大型總部之一位於**蓬萊群島** |

- 除上述之外，另有**不完全屬於五方的陸地、其他小型勢力、無主地、禁地**。

### 4.3 大道洲與絕天海
- 三千年前的大戰**將大道洲打成兩半**，中間已成新的海域，即**絕天海**。
- **兩塊陸地皆有人居。**
- **資源結構（v22 新增）**：**北大道洲靈脈較豐，但土地貧瘠**；**南大道洲除靈脈外資源豐富**。
- 兩者形成**雙向依賴**：**靈氣南下，物資北上**。南方**高度依賴**北方的靈氣輸入；北方對南方物資則**部分依賴，自給仍可**。
- **正道門舊址位於這片海域下方。**
  - 古戰場影響殘留至今。
  - 有價值之物**早在當年就被正道門殘餘組織打撈殆盡**。
  - 如今只剩**極度混亂的靈氣環境**，使中央大片區域難以航行。
- **混亂靈氣對練氣與煉體兩者皆有害**，皆難以通行。

### 4.4 兩岸航路
- **仍可往來**，但紊亂靈氣造成**海象惡劣**，並孕育出**適應該環境的特種生物**。
- 航線周邊已形成：
  - **專門跑這條航線的船隊與護航行業。**
  - 該航線**同時是靈氣運輸線**（v22）。
  - **兩岸港口城市因此繁榮。**
- 明確排除：此航線**並非**走私與黑市的主要通道；亦**未**形成專門的特種生物獵人群體。
- 航班依靠**商會與船隊**經營：有些是**門派自營**，有些是**獨立經營**，並以商會、船隊名義加入正道聯盟。

### 4.5 禁地
- **依地點而異，成因各不相同。**無統一性質。

### 4.6 無主地
無主的原因**三種情況皆存在**：
1. 貧瘠或偏遠，沒有勢力願意接手。
2. 各方都想要但互不相讓，維持空白。
3. 有**小型勢力實際控制**，只是不屬五方。

- 不屬五方的小型勢力**靠什麼存活，依勢力而異**，各有各的生存之道。

### 4.7 福爾摩沙島（v28 新增）

- 位於蓬萊群島南端、大陸東側的小島。
- **在正道門分裂多年之後，效法波希特米亞聯邦，創立了自己的民權政府。**
- **完全獨立，並非正道聯盟成員。**
- 未被大道洲納入管轄的原因：島上有一處秘境「**大肚秘境**」，使**整座島成為天險**——**除島民外，外人難以出入**。

> 這是 7.7「不存在獨立生存的選項」目前唯一的實質例外。它依靠的不是庇護，而是地理上的不可及。

## 六、三千年前的大戰

### 6.1 起因
- **天絕大帝**：當世最強的大帝境強者。雖為天下第一，卻**無心拉幫結派**，僅創立了一個小門派。
- **【v25 增補】**他**不結黨、不建立勢力，但推動山上宗門與世俗界的融合**——形象親民，以各大行會（百工百業）為載體，推動一次全面的技術與世俗整合。他推動的是**一個沒有他也能運作的方案**，而非一個屬於他的組織。詳見第十三章。
- **證道時點**：約於**4300 年前**證道，3000 年前戰死——**擔任大帝的全部時間為 1300 年**。
- **正道門**：當時全世界第一大門派，擁有**五名大帝境強者**。
- 正道門自詡當世正道，**不能容忍天絕大帝留下道統**，於是設計困住天絕，並趁機**屠滅其滿門**。

**開戰的真正成因（v37 新增）**
- 正道門容不下他的**兩者兼有**：**其道統本身不容於正道**，**且其文明方案威脅門派秩序**。
- 天絕之道為**排斥、拒絕、否定**，而他推動山上與世俗的融合——**兩者是同一件事的兩面：否定既有秩序**。他不是碰巧悟了否定之道又碰巧推動融合，而是**因為他是那樣的人，才能悟那個道**（見 3.1）。
- **正道門知道他在推動融合，但不知其深度。**

> 他們看見的是一個推動融合的親民強者，於是動了殺心；他們沒看見的是那個方案底下的測量學革命與知識網絡——**而他們自己正是那個網絡唯一測不出來的東西**。
>
> **他們殺他，是因為看見了表層；而他們沒能毀掉的，正是他們沒看見的那層。**三千年後的清算之所以「廣泛但不精確」（13.9），根源在此。

> 那場大戰是一場**復仇**。正道門是加害者。

### 6.2 經過與結局
- 戰鬥打得天崩地裂，**將大道洲整片大陸打成兩半**。
- 尾聲：天絕肉身已毀，五名大帝雖重傷但仍在。
- **天絕以靈魂形體發動秘法，一次攻擊五人，成功殺盡五名大帝境**——代價是自身**靈魂撕裂、部分缺失**。
- 正道門所有大帝境**身死道消**；天絕肉身崩壞，僅餘靈魂碎片。
- **靈魂的拆分是戰鬥的自然結果，非任何人刻意為之。**
- 正道門因內部分歧嚴重、又遭此打擊，就此分解。
- 天絕大帝是**距今為止最後一名大帝**。

### 6.3 靈魂碎片現況
| 碎片 | 現況 |
|---|---|
| 第一份 | 由正道聯盟封印 |
| 第二份 | 由波希特米亞聯邦取得，研究中 |
| 第三份 | 由荒阪集團取得，研究中 |
| 第四份 | 於戰鬥當下即湮滅 |
| 第五份 | 流落在外，無人知曉 |

- 碎片為自然散落，各方於三千年間**陸續取得**。
- **現存碎片若重聚，結果無人知曉，且與其道的釋放與否無關。**

### 6.4 天地的損傷與知情結構
- 那場大戰**改變了天地環境，破壞了某種條件**——這正是三千年來無人成就大帝的原因。
- 這不是「尚未出現」，而是**已不可能出現**，除非該條件被修復。
- **僅極少數頂層人物知情**，這些知情者即是**山巔人**，且僅知曉「部分」真相。
- **隱瞞動機**：各自想獨佔修復的可能性；頂層之間有共識協議，共同封鎖。
- 明確排除：並非為避免社會崩潰或全面戰爭。
- **知情者的圈子無固定組織**，僅是彼此心知肚明。

**條件與修復（v12 新增，原待裁決項目 21 結案）**
- 被破壞的條件**即道門**（見 3.8）。
- **無人完全確知**條件的全貌，**包含山巔人在內，皆僅知曉部分**。
- **修復真實存在且可達成。**
- **修復的效果為全球性**：一旦修復，**人人可走**。
- 天地**正在極緩慢地自行恢復**；**若不藉助任何手段，完全自行恢復需萬年**。
- **隱瞞動機的界定**：所謂「獨佔修復的可能性」，**獨佔的是先機**。修復效果雖為全球共享，但 3.1「每一條道的終點只能有一人」依然有效——**先修復者可先佔席位**。
- **修復手段的線索零星散落**於**遺跡與傳承、天絕靈魂碎片、各勢力內部檔案**之中，**分散存在**。

### 6.5 戰後：亞特蘭蒂斯的入侵
- 正道門覆滅後不久，**三千年前的亞特蘭蒂斯帝國趁虛而入**。
- 殘餘門派被迫團結擊退之——這是三千年來**唯一一次全員一致**。
- 正道聯盟因此是**在戰場上被逼出來的臨時同盟**。

### 6.6 歷史的處置

**亞特蘭蒂斯帝國**
- **官方否認或改寫該段歷史**，境內僅皇室與最高層教會知情。

**正道聯盟（v18 新增，原待裁決項目 8 結案）**
- 對「正道門是加害者」一事**裝傻，完全淡化**——**不銷毀、不否認，只是不提**。
- **知情範圍為山巔人層級。**
- **部分正道門的原生分支保有機密檔案。**
- 原生分支在聯盟內**是否具特殊地位：依個案而異**。
- 原生分支自身**是否知悉檔案內容：依門派而異**。

## 七、正道聯盟

### 7.1 起源
- 源自上古第一大門「**正道門**」，於三千年前的大戰後分解而成。
- 聯盟歷史三千年，正道門本身遠早於此。

### 7.2 治理結構

- 常設機構名為「**天祠**」，職能僅限**協調與仲裁**。
- **無盟主、無領導者**，決議對成員無強制力。
- 領地內治理制度**依門派而異**；跨領土遷徙自由度亦**依門派而異**。

**天祠的組成**
- 由「**常任理事委員**」組成。
- **常任理事委員即正道碑上的常任成員，同一批人。**
- 因此所謂「**聯盟高層**」，指的就是**上碑者**。
- **無固定名額**；席位屬於上碑的**組織**，目前**為 16 個**。
- **代表人由門派自行指派**——**席位屬於門派，出席者只是代理**。

**席位的取得與喪失（v19 新增）**
- 門派被擠下碑時，其代表**不立即失去資格，有數月的緩衝期**。
- **緩衝期內僅保留席位，不得表決。**

> 碑即時偵測增減，委員資格卻有緩衝——**碑的狀態與委員會的狀態並非同步**。

**決策規則（v17 新增）**
- **採一致決**，適用於**大部分事項**。
- 但**一致決並無絕對強制力**——**委員會內部具有階級與派系**。
- **階級的來源**：門派底蘊、個人實力、聲望、手段等，**並無絕對標準**，只是**大部分時候等於碑上的排序**。
- **派系**：委員會內**有長期存在的幾個派系**。

**天祠下轄機構**

| 機構 | 職能 |
|---|---|
| **窺天局** | 情報搜集。**其職掌之一為正道碑的管理。****以人力情報為主，不從事通訊監控。** |
| **暗影隊** | **直屬天祠的戰鬥部隊，為天祠的私人武裝力量，想做什麼都可以。** |

> **界定**：暗影隊**僅對內，不介入成員之間的糾紛**。7.6 所述「機構不指揮、不執行」係針對海捕令的執行程序，兩者並行不悖。

### 7.3 成員資格
- **成員不限於修仙門派。**商會、船隊等組織同樣可以登記加入。
- 聯盟因此更接近一套**登記制的保護體系**，而非單純的宗門同盟。

### 7.4 正道碑（上古仙器）
- 原為正道門的**門內評比工具**，分裂後沿用至今。
- 自動評比登記者的綜合實力，上碑者**自動取得常任成員資格**。
- **完全自動運作，無法手動修改**，可自動偵測增減，迄今從未失誤。
- **從未限定血脈**。**評比範圍僅限主動登記者**。

**登記單位（v19 確認）**
- **登記與上碑的單位是組織**（門派、商會等），**不是個人**。
- **散修個人不可單獨上碑**，無論實力多高——**碑只認組織**。
- **一組織一席**，不得持有多席。
- **非門派組織理論上可以上碑，但三千年來從未發生。**
  - 原因：商業組織**缺乏完整戰力體系與道統傳承**，無法如門派般有效產出高階戰力。
- **碑的管理由窺天局負責。**碑本身不可竄改，窺天局所掌握的是**碑的資訊**。

### 7.5 身分與庇護
- 加入需**主動登記**。成員享有庇護。
- 違反仲裁的代價是**失去「正道」身分**，僅靠聲譽與道義壓力維繫。
- 「正道」原是門派名稱，非道德判斷。

### 7.6 海捕令
- 由機構內**常任成員合議**發布（一致決，見 7.2）。**個人與組織適用同一程序**。
- **歷史上約數十年發布一次。**
- 效力：撤除正道庇護，**任何成員皆可直接攻擊並瓜分**。
- 機構不指揮、不執行，其實權是消極的——只能取消保護。

### 7.7 非成員的處境
- **從未加入者與被逐出者處境完全相同**：皆為可自由攻擊、瓜分的對象。
- 被逐出者：主動追剿、社會排斥、只能轉為散修或投靠他方。**不存在「獨立生存」的選項。**

### 7.8 全員一致（國力 3.0）
- **唯一觸發條件**：外部生存威脅。
- **三千年來僅發生過一次**。

### 7.9 行政區劃（v8 改寫，原待裁決項目 23 結案）

**層級**

> **洲 → 州／省 → 郡／府 → 市／城**

- **劃分方式與原因沒有固定規則，每個地方都不一樣**，可能出於地理、歷史、政治、文化等因素。
- **門派並非地理概念，而是組織概念**，不構成行政區的劃分範圍。

**各級主官**

- **州／省為純粹的地理稱謂，沒有管理者。**
- 實際治權存在於**郡／府**與**市／城**兩級，但**不一定**：有些地方有市長，有些有郡主、府主。
- 主官的**產生方式不作規定**。

**權力與壓迫**

- **聯盟高層（即上碑者）對各所轄行政區高層存在有形無形的長期壓迫。**
- **「不希望城市獨立」是聯盟高層的長久共識。**
- **壓迫路徑與權力結構極為複雜，沒有單一模板。**

### 7.10 門派與城市的關係（v7 新增）

> **適用範圍界定**：本節所述為**大道洲（正道區）反覆出現的常見型態**，**非統一制度**。他方不適用。各城條件依個案而異。

- 門派**通常擁有自己的領地，多為一座山**，世稱「**山上**」。
- **門派極少直接設立於城市之中。**
- 山上門派通常**至少擁有一座直屬城市**，該城**與門派同名**，**由門派直接管轄**。
- 門派所據之山**即靈脈所在**——**佔山即佔靈脈**（見 9.7）。
- 其餘大量城市**與各門派合作，成為附屬**，雙方**互相交換利益**。
- **附屬城市為自治。**
- **交換的利益依個案而異，無通則。**但大致形態為：
  - **附屬城提供**：人才、勞力、商品等**民生物資**。
  - **門派提供**：**保護與武力支援**，以及**靈氣資源與功法**。
  - **靈脈本身並非附屬城拿出的對價。**
- 一城**可同時附屬於多個門派，但少見，且容易引發衝突**。
- 多重附屬引發的衝突**各憑實力解決，聯盟不介入**。

**附屬城市自行登記加入正道聯盟**
- **從未明文禁止，但默認不行。**
- 阻力**並非來自禁令，而是來自城市自身**——**怕失去與門派的合作**。

#### 7.10.1 樓蘭城毀城事件

- **一千年以上之前**，附屬城市**樓蘭城**嘗試自行登記加入正道聯盟。
- 登記失敗，**樓蘭城原本的上級門派促成報復，整座城市被毀**。
- **記錄並未被抹除**，而是**被刻意忽略與淡忘**。
- **原因**：抹除一座城市在道德上有瑕疵，**聯盟高層為自身顏面選擇隱匿與淡化此事**。
- **記錄現存於門派典籍與聯盟檔案之中**，民間無從查證。

> **今日恐懼的來源與此事無直接關聯。** 現今城市不敢獨立，是因為**聯盟高層對各所轄行政區高層長期的有形無形壓迫**所塑造，而非對舊事件的記憶。

### 7.12 委員會的派系結構（v32 新增）

> 上碑門派**目前為 16 個**，即正道聯盟的統治集團。各佔一山、即各佔一條靈脈（見 9.7）。

**道統分類**
- **大致有分，但不嚴格**——分類存在於習慣與認知之中，而非制度。
- **採粗分**：**劍、丹、器、卜算、其他**。

> **原生派不掛專業。**七星宗門的名字裡沒有道統，只有位階——因為**它們繼承的是正道門的核心道統**，而核心道統不是「做什麼」，是「怎麼修」：**它不歸類，它是分類之前的東西**。

**五個派系**

| 派系 | 內容 |

**七星宗門（v33 新增）**
- **天樞、天璇、天機、天權、玉衡**同屬一脈，**七家同源**，皆為原生派。

**上碑門派細部（v40 起陸續補充）**

**天錦門（第 14 名／煉器／南）**
- **煉器宗門**。碑上排名靠後，但確為上碑宗門。
- 門派獨有的布料「**雲天錦**」是**大道洲最好的靈衣材料**：防禦力高、可儲存靈氣、舒適且色彩極佳。
- 因此成為**世界知名的布料商**；其餘煉器商品同樣出色。
- **儲存能力**：一般版本屬低階；**另有可儲存高階靈氣的特殊版本，但產量極少**，不足以撼動偉恩的高階容器地位（見 9.7）。
- **技術獨門不外傳，僅售成品。**
- 屬第四派系，**仍需依附其他派系**。

> 偉恩買得到雲天錦，卻**造不出雲天錦**——一個以材料技術著稱的勢力，在這一項上只能當客戶。

**分布與位階**
- 16 席的**南北分布大致均衡**（北 7、南 9），但**北方門派平均排名更靠前**——前六名中北方佔五席。
- **原生分支普遍排名較前。**
- **南北地域是一條橫切各派系的線**，並非獨立派系。

> **結構要點**：席位數南北相當、實力北方居優——於是**北方掌握位階，南方掌握票**。在一致決之下，南方擋得住，卻推不動。

### 7.11 雙重登記（v14 新增，原待裁決項目 16 結案）

- 門派同時登記於**聯邦監管制度**與**正道聯盟**，**兩邊皆未明文禁止**。
- 實務上**僅有極少數案例**，且**低調維持至今**。
- 登記正道的動機**依個案而異**。
- **正道庇護可跨境進入聯邦**，但**會被聯邦視為組織犯罪**。
- **聯邦知悉並監控**這些門派。

> **界定**：登記本身合法，**行使庇護則構成犯罪**。

## 八、世界秩序

### 8.1 世界公約
- 約束五方不明目張膽直接開戰。**無執行機制**，效力純粹來自相互威懾。

### 8.2 遺跡與傳承的爭奪
- **無明文規範**，靠五方**互相監視與默契**維持。
- 默契**內容不固定**，每次由各方高層依當次情況個別敲定。

### 8.3 禁忌領域
- **無人明文界定**，屬心照不宣的默契，模糊地帶極大。

### 8.4 常規武力的效力（v23 修正）

**對練氣修士**
- 常規部隊對**高階練氣修士不具實質作用**。
- **唯一的例外是波希特米亞聯邦**：其常規武力憑**反修士科技**得以有效作用於修士。該技術境外僅有零星流出，此例外**不適用於其他勢力**。

**對煉體者**
- 常規部隊對**高階煉體者具有部分作用**。
- **反器材步槍、穿甲彈、麻痺彈**等針對煉體者的武器，是**全球通用技術，各方皆有**。
- 主要反制方式仍是**大量修士的人海戰術**。

**戰略定位的差異**
- **修士是戰略武器，煉體者是戰術武器。**
- **玉璞境之上，普遍法術的涵蓋範圍即可涵蓋一座城市**——單一個體具備城市級破壞力，這是軍隊無法用人數交換的東西。
- 煉體者**大部分為單體傷害**，無法一人屠一城，故人數、火力與消耗等常規邏輯對其仍然有效。

> **玉璞境是一條全球通用的界線：一個人從此開始不能用常規手段處理。**
>
> 此對比描述一般高階戰力，**不涵蓋武神與大帝**（見 2.4）。

## 九、社會、經濟與階級

### 9.1 「普通人」的成因
世上大部分人都能修鍊靈氣。「普通人」是**經濟結構**的產物：
1. 能修煉 ≠ 有資源修煉。
2. 多數人終其一生只能停在最低境界。
3. 修煉需投入大量時間，多數人為生計選擇不修。

> 明確排除：門派成員資格**不是**分界線。

### 9.2 功法與靈氣資源的取得管道（四者並存）
1. 加入門派，以勞役或忠誠換取。
2. 市場購買，**有錢即可取得**。
3. 受僱於散修或小宗門，品質參差。
4. 遺跡與傳承——高風險的體制外途徑。

> **例外**：波希特米亞聯邦境內不適用第 2 項。

### 9.3 品質上限
- 合法市場只流通中低階。**高階功法僅在黑市流通**，來源多為遺跡與盜取。

### 9.4 黑市（四種構成並存）
1. 荒阪集團主導經營。
2. 各地自發形成的地下網絡。
3. 散修與被逐出者組成的鬆散體系。
4. **門派內部人員暗中參與**，屬半公開的秘密。

### 9.5 跨勢力人才流動
- 人才流入波希特米亞聯邦，**聯邦樂於接收**，無門檻，其他勢力亦未阻止外流。

### 9.6 長壽與權力固化
- **上層長期不更替，權力高度固化。**
- **修士與凡人形成兩種不同的時間感與生活節奏。**
- 明確排除：長壽者**並未**退居幕後，也**並非**決策保守。他們長期在位且持續行動。
- **權力幾乎不透過鬥爭或讓位而更替。**普遍現象是：修士察覺自身壽元與精氣神觸及瓶頸時，因長壽而生的怕死會驅使他們**選擇長期閉關**續命。
- **閉關者可被喚醒，但代價極高——會損耗其壽元**，且**依個人而異，無統一規則**。

### 9.7 靈氣的採集、儲存與輸送（v22 新增）

**來源**
- **定點與瀰漫兩者並存**——如同油田與太陽能：既有可隨處採集的天地靈氣，也有**特定的靈脈與礦點**。
- **靈脈是高品質靈氣的產地。**

**儲存**
- 靈氣**可儲存於特製容器**。
- **容器分階**：**低階容器已普及**，**高階容器由偉恩企業主導**，他方僅有**次級替代品**。
- **高階容器的優勢在於「可儲存的靈氣品質」**——低階容器裝不了高品質靈氣。

**輸送**
- **短程可靠管線**，有效距離**僅數公里**。
- **長程一律靠容器運送。**
- 因此**世界上不存在全國性的靈氣管網**。

**日常產品型態（v24 新增）**
- **供能方式比照插電與電池**：**固定式產品接城內管網**，**攜帶式產品內置容器**。
- **發展程度歪斜**：**部分領域遠超現實科技，部分領域則完全空白**——此世界並非「現代社會換個能源」。

**科技的定位（正式原則，v26）**
> **靈氣能做到的事，取決於法術與能力天賦，而這些個體差異極大。**
> **科技的功能是彌平差距**——彌平普通人與修士之間、以及不同階層修士之間的落差。
> **這不只是戰力上的，更多是生活上的。**

此原則是 13.3「資質不應成為決定世界的方式」的現代延續：當年行會證明了靈氣是世界的性質而非人的天賦，**今日的靈氣科技把那個證明變成了商品**。

**領域分布**

| | 領域 |
|---|---|
| **遠超現實科技** | **材料與能源**、**交通與運輸** |
| **完全空白** | **電力與電子**、**石化** |

- **化學並非空白，空白的僅是石化**——碳氫燃料那一整條產業鏈在此世界沒有存在的理由。反修士科技的化學路線（見 10.3）不受影響。
- **電子元件本身空白**，但**存在功能對等的靈氣版替代品**；資訊網路即建立在此之上。

**資訊與通訊**
- **存在類似網際網路的資訊網路。**
- **全球互通，但各方各有管制。**

**增強修士（禁忌前沿，v38 新增）**
- **靈氣科技可以增強修士**，但此事**屬於秘密與禁忌的前沿領域**。
- **技術仍在實驗階段，代價極大**——尚無成型的成果。
- **世界默許科技讓弱者跟上，不默許它讓強者更強。**同一套技術往上推，就成了禁忌。

> 這是 v26 那條原則的另一面：**彌平差距是它公開的那一面，拉開差距是它禁忌的那一面。**

**由此形成的地理**
- **大多數城市依靈脈而建。**
- **門派所據的山即靈脈所在——佔山即佔靈脈。**

## 十、勢力細部

### 10.1 偉恩企業（國力 2.0，滲透型）
**力量支柱排序**：血脈世家 › 自有頂尖修士與武夫戰力 › 靈氣科技研發與生產壟斷 › 資本與跨國供應鏈

- 偉恩家族**已有數千年歷史，遠早於同盟會，亦早於聯邦建國**。

> 同盟會的理念是「**資質不應成為決定世界的方式**」（13.3），而偉恩是一個以血脈立身、靠資質篩選族人的家族——**它不可能簽下那份文件**。10.1 的「檯面下摩擦」因此不是後來產生的，**是從一開始就沒談攏**。

**與三千年前大戰的關係（v36 新增）**
- **完全未參與那場大戰**——距離太遠，人在歐姆尼亞洲。

- **偉恩沒有天絕的靈魂碎片**：**歷史上沒搶到**。它未曾參戰，故戰後也分不到。

> **它不是與那段歷史無關，它是那段歷史的另一方。**三千年前的清算掃平了大道洲的行會，而偉恩在另一塊大陸上安然無恙——**它是那個保護網絡唯一以組織形式活到今天的部分**。

**血脈**
- **性質為高修煉資質**——**不指定方向，只提高上限**。故家族成員修士與武夫兼有（見力量支柱第二項）。
- **無保底機制**（與亞特蘭蒂斯不同）。血脈只是傾向，實力的維持**依靠家族體量與殘酷的內部競爭機制**。

> **帝國是少而穩，偉恩是多而狠。**

- **核心位於高譚市**（歐姆尼亞洲東岸，波希特米亞聯邦境內）。
- **偉恩家族完全掌握該市的經濟、行政與司法**，市政府的司法與行政機關**僅為傀儡**。
- **與正道聯盟**：地域性與道統**完全不同**，從未屬於正道體系，獨立發展至今。
- **與波希特米亞聯邦**：形成**軍事工業複合體**，國家與企業各持部分機密技術，表面合作，檯面下時有摩擦。
- **法律地位**：**名義上受聯邦法律管轄，但聯邦實務上不敢執法。**

### 10.3 波希特米亞聯邦（國力 1.8，領土型）

**建國史（v20 新增）**
- 聯邦誕生於**約 2800 年前**，即三千年前那場大戰**之後**。
- 在此之前，歐姆尼亞洲為**多個小國並立的戰國時代**。
- **十二位志同道合者組成「波希特米亞同盟會」**，一個非政府組織。
- **【v25 修正】成立動機為跨地區的科研整合**——各地測量學傳承程度不一、多中心而無標準，同盟會即為三千年後重新出現的**校準網絡**。**「致力於大陸和平與人民福祉權益」的政治性格是後來長出來的**，一如當年的秘密結社。
- 十二人中有**政治家、哲學家、科學家、作家**等，**有凡人也有修士**——**境界並未成為他們的隔閡**。
- 領導者為**恩菲・華盛頓**，後為聯邦國父。**他是凡人，現已逝世。**
- 同盟會執行多年和平運動後，認為**僅靠和平示威與遊說無法解決人民問題**，遂開始以各種方式介入各國，**引發示威遊行乃至革命**，最終掀起大規模革命熱潮，**波希特米亞聯邦就此建立**。
- **十二先賢今日僅少數在世，且皆為修士**——凡人先賢皆已逝去。

**政體**
- **五權分立。**
- **修士僅掌握監察權與一半的立法權**，其餘各權互相搭配合作。
- **立法權**：分上下議院。**上議院由修士組成，下議院由凡人組成，兩院權力相等。**
- **監察權**：由修士組成，具**糾舉與彈劾權**，但與行政、立法相互制衡，避免濫權。
- **國家首領分為大總統與總理**：
  - **大總統由修士擔任**，現任為十二先賢之一的**柏拉圖・斯坦尼**。
  - **總理由凡人透過選舉產生。**
- 由多個區域行政單位組成，**中央集權**。**名為聯邦，實為統一國家——「聯邦」自建國起即為政治修辭，並非集權化的結果。**

> **定性修正（v20）**：聯邦**並非「凡人統治修士」**，而是**凡修共治，修士受法律管轄**。其獨特之處在於修士的權力**被制度切割**，而非被凡人支配。

**管轄修士的三重支柱**
1. 靈氣科技製成的管制手段，可監控或壓制修士。
2. 聯邦自有的高階修士武力，專責執法。
3. 高階修士被吸納進體制，以利益換取服從。
> 明確排除：修士**不享有**法律特權。

**增強修士的研究**
- **偉恩亦在進行，但更為隱密。**

**反修士技術**
- 由**國家與偉恩企業各自掌握部分機密**，任一方皆無法單獨完整部署。境外僅有零星流出。

**反修士科技的內容（v23 新增）**
- **作用原理以壓制為主。**
- **效果**：對高階修士**大幅削弱，但仍具威脅**——並非使其失效，而是**使其進入可用軍隊、人數與代價處理的範圍**。
- **對煉體者幾乎無效。**
- **來源**：與天絕靈魂碎片的研究**部分相關**，但非全部。

**兩條技術路線**

| 路線 | 原理 | 應用 |
|---|---|---|
| **靈氣無效化／中性化** | 以特殊力場使靈氣在範圍內**失去攻擊性** | 護盾、衝擊波、靜滯力場等 |
| **靈氣破壞／腐蝕** | 以特殊礦物、輻射或化學物質**主動反向破壞靈氣** | 各式攻擊性裝備 |

- 兩條路線**皆有可攜式與固定式**。
- 經多年發展已衍生多種類型：**實體靈氣彈藥、靈氣能量彈、反靈砲、靈能護盾**等。
- **執法單位與軍隊各有不同變體裝備。**

**部署原則**
- **依殺傷性與特殊性決定部署密度**：**越特殊、殺傷性越高者部署越少**，反之越多。

**修煉體系**
- 功法為**管制品**，境內無合法市場管道。
- 途徑僅二：官方修煉機構、民間門派（須登記受監管）。
- 官方體系為**多軌教育制度**：普通、技職、軍方、私人並行。
- 准入條件並存：天賦測驗公開招收、服役或長期義務、公職與軍方限定。
- **天賦測驗僅供分流參考，後續以實際表現為準。**

**黑市管制**
- **黑市與走私為法律明文禁止**，盛行但不被容忍。

**執法與腐敗（v10 新增）**
- **腐敗程度為「中」**：局部腐敗，**依層級與個案而異**，無統一狀態。
- **主要形式為偉恩企業與荒阪集團的滲透**——並非修士收買執法者，亦非官員參與黑市分潤。
- **中央部分機構正在追查。**
- **不設專責的內部監察機構。**

**軍事（v9 新增）**
- **兵役制度**：募兵制。**戰時可轉為徵兵。**
- **修士編制**：編入常規部隊、另編專責部隊，**兩者並行**。
- **投射能力**：**具備跨海遠征能力。**

**戰力性質**
- **頂尖戰力弱於正道、偉恩、亞特蘭蒂斯**，憑國家機器與反修士科技維持恐怖平衡。

### 10.4 亞特蘭蒂斯帝國（國力 1.1，領土型）
**力量支柱排序**：皇族血脈與保底機制 › 超級上古秘境 › 政教合一的宗教統治 › 軍事力量（教會武裝與皇室精銳）

**政體**
- **世襲皇室，政教合一**，主張**天賦皇權**。
- 皇族血脈具**保底機制**，可強制誕生高天賦後代。

**波賽頓大帝（v29 新增）**
- **帝國的創立者，教會信仰的對象。**
- 曾**掌握「海之道」**，約於**數萬年前證道**。
- **早已消散。**依 3.9 的機制，其本體凋零、道身融入海之道成為養料——**海之道現已釋出，只是道門已毀，無人走得上去**。
- **皇室為其直系血脈。**
- **教義稱其升華為神，仍在注視。**
- **皇室最高層之中，僅極少數知情其實已經消散。**

**血脈**
- 皇族血脈具**保底機制**，可強制誕生高天賦後代。
- **所產出的天賦為「水與海」屬性的親和力。**

**修煉體系**
- **以練氣為主。**

**超級上古秘境**
- 帝國起源於此，**皇室完全掌握**，並據此建立宗教。
- **秘境早於波賽頓即已存在**，並非其遺產。其真正來歷至今不明。
- 限制：血脈鎖定僅惠及皇室少數；能力有上限，**無法製造軍隊**；**不具攻擊能力**。
- 保護形式：防禦屏障 ＋ 預警偵測，但**僅於皇都周邊生效**。不供給全國靈氣資源。

**都市與建築（v30 新增）**
- **風貌梯度**：**越接近中心越宏偉但保守，越接近邊陲越原始但與世界接軌**。
- **主要材料**：**海洋材料、礁石、金屬**。
- **與海的關係**：陸上城市面海、部分建於水上、**並設有水下城區**，三者並存。
- **皇都規劃**：**神殿與皇宮共構中心**——並非兩座相鄰的建築，而是一座無法拆分的核心。
- **水下城區的居住條件**：**會水法、可入水生活者皆可居住**；否則**必須長期配戴靈氣輔助裝置**。

**服飾**
- 主調為**貼身輕薄**，以適應水中活動。
- **階層外顯於服飾，一望可辨。**

**科技定位（v30 新增）**
- 帝國**擁有自身的科技實力**，靈氣輔助裝置等**可以自產**，同時也有外來輸入品。
- **定位為自成一系**：**強於造物，缺乏計量與基準的傳統**。它可以造出極精良的東西，卻**做不到把世界讀成數字**。
- **與偉恩相比，特定領域相當或超越。**
- 帝國科技**少量流出**境外。

> 此與 13.11「帝國無科研傳承、不具測量能力」並不衝突：**帝國缺的不是技術，而是測量學那一支傳統**——絕對讀數、共通基準、跨時累積的方法。

**邊陲地帶（四重狀態並存）**
1. 有效控制薄弱，實質半自治。
2. 偉恩與荒阪滲透嚴重，經濟受外力掌控。
3. 宗教組織代行統治，教會即地方政權。
4. 治安敗壞，散修與逃亡者聚集。

**教會與皇室**
- 表面忠誠。**皇室成員有限，無法完整管理國土**，故教會大部分時間半自治。

**軍事（v9 新增）**
- **兩支武力並存，互相牽制**：皇室軍與教會武裝。
- **教會武裝規模較大**；**皇室軍為精銳部隊**，惟**教會同樣擁有精銳**。
- **皇室精銳的來源**：皇族血脈者與境內選拔的高階修士**兩者兼有**。
- **動員方式**：**皇室下令、教會執行。**
- 帝國不具反修士科技，故其常規部隊對高階修士**無實質作用**（見 8.4）。

**風俗與宗教生活（v31 新增）**
- **宗教深入日常生活的每一個環節。**
- 宗教生活的主要形式為**以海為核心的祭典與節慶**。
- **水法是基本教養**——一般帝國人普遍習水法。

> 信仰、生計與修煉在帝國是分不開的：**下水就同時在幹活、在修行、在敬神**。

**對外姿態**
- 國風排外，**半鎖國**，除必要商業活動外不對外往來。

**排外的具體表現（v31 新增）**
- **外人入境皆需許可**，惟**邊陲管制極鬆**——規則存在，執行有梯度。
- **可經商，不可定居。**
- **態度**：**邊陲不敵視，中心敵視。**
- **例外**：帝國**接納擅長水法的外人**，但其在**文化與生活方式上仍會被本地人排斥**。

**歷史包袱**
- 三千年前曾趁正道門覆滅之際入侵，遭殘餘門派聯手擊退。官方否認或改寫該段歷史。

### 10.5 大地綜合行會（第六股勢力，v39 新增）

> **形態特殊**：橫跨全世界、**無領土、無戰力**，卻不可或缺。不列入 5.1 的國力表，因其力量與可動員實力無關。

**源流**
- 即三千年前遭清算的**大地綜合行會**（見第十三章）。
- 清算後**並未解散，而是地位降低**，轉入地下。
- **保管期約五百年**，其後歷經三千年的休養生息與轉型，並得到**波希特米亞聯邦的扶持**。
- **同盟會出自行會，後分化而出。**

**現況**
- 已成為**橫跨全世界、具公信力的科學組織**。
- 掌管**測量、檢驗、計算、基準**等一切社會的基礎數值。
- **對基礎科學的研究亦為權威。**
- **自身毫無戰力，但不可或缺。**
- **在大道洲已被接受，標準通行。**

**與其他勢力的關係**
- **行會後裔與學術機構無自己的地盤，寄居於各方境內。**因此不在任何權力表上，也不會成為攻擊目標。
- 聯邦、偉恩、荒阪的測量能力，**可能有一部分本來就源自於它**。

> 對照荒阪：荒阪是**刻意分散以求不可摧毀**，行會則是**從來就沒有中心可言**。

### 10.6 其他非五方地區

- **總體份量相當可觀，但分散而無法整合。**這正是它們不構成一方的原因。
- 已定名者：**蓬萊群島**（無主自由貿易區）、**福爾摩沙島**（天險自治）。詳見 4.1、4.7。

## 十四、世界真相（v42 新增）

> **本章凌駕於現有一切設定。**其他章節所述的道門、大帝消散、正道門的罪，皆為此層之下的現象。
>
> **知情範圍：僅已死的大帝們知曉。**沒有任何在世者知道，也沒有任何知道的人能回來說——知道真相的條件是證道，而證道之後便開始消散。

### 14.1 道的本質

- **「道」是世界底層法則用來保護世界的方式。**
- **維持道，就是維持規則與秩序**——類似逆熵。
- **道的維持，以大帝的道身作為養料。**
- **一旦過久沒有新的養料，道則便會退化。**
- 道則退化，**「混沌」就會滲入，造成混亂**。

> 3.9 所述「凋零之時道身融入該道成為養料」並非比喻，而是**系統的燃料補給**。大帝的一生就是走上去、換取執掌權、最後**把自己燒成維持世界的燃料**。「證道是一場交易」（3.8）因此是字面意義的：**世界給你權柄，你把自己抵押給它。**

### 14.2 現況：三千年沒有新養料

- 道門毀於三千年前，此後**再無人證道**，也就**再無新的養料**。
- **退化已經開始。**
- **退化與「天地自行恢復需萬年」是同一過程的兩面**——世界正在修補那道門，但它是用自己的秩序在補。**等待本身就是消耗。**

> 所有勢力爭奪的「修復道門」，其真正意義**不是誰能成帝，是世界還撐不撐得住**。山巔人以為自己在爭一個席位，實際上他們爭的是**補給線**——而沒有人知道這件事，因為唯一知道的人都已經燒完了。

### 14.3 可觀察的徵候

- **靈氣紊亂增加。**
- **秘境與禁地擴張。**
- **「混沌滲入」已有零星事件**——只是尚無人將它們連起來。

**觀測能力**
- **行會的千年帳簿測得到道則退化**，斥力衰減僅是徵候之一。
- 但行會**只測到異常，尚不解其意**。
- 13.10 已定斥力衰減是基礎科學常識、凡研究者皆知——**徵候是公開的，只是沒有人知道那是徵候**。

### 14.4 混沌的性質（v43 結案）

**它不是一種東西，是一個過程的不同階段**

- **初始無實體，僅有異象。**
- 隨時間推移，**開始出現實體、神智，甚至意志**。

> 世界不是在對抗一個敵人，是在**看著一個敵人慢慢成形**。混沌的成長曲線與世界的衰退曲線是同一條——**每一年沒有新養料，它就往「有意志」那一端多走一步**。

**成長速度依地點而異**

| 環境 | 影響 |
|---|---|
| **靈氣或道則濃郁處**（高階修士聚集） | **減緩**異象生成 |
| **貧瘠、偏遠、無人之地** | 異象**較多**、生成較快 |
| **禁地與秘境** | **例外，極易產生異象** |

> 文明的分布，無意間也是防線的分布。而 14.3 已定秘境與禁地正在擴張——於是形成循環：**混沌讓禁地變大，變大的禁地又更容易生出混沌**。

**對抗方式**
- **已凝聚的實體可以被殺死。**
- **但源頭不除則再生**——這是一場消耗戰，不是一場決戰。

**規則地位**
- **混沌不受「道」的規則約束。**
- 一道一人、道不可檢測、身死道消、消散不可言說——**這些規則管得住大帝，管不住混沌**。它是規則退化的產物，**從一開始就在規則之外**。

**現有零星事件的表現**
- **地點性的異變與異象。**
- **人與生物的異化。**
- **規則失效（法術、因果出錯）。**

6. **亞特蘭蒂斯的位置解釋了太多事。**它夾在正道與聯邦之間的海域——說明了三千年前它為何能趁虛而入、為何半鎖國卻仍維持「必要商業活動」、以及 1.1 的國力為何排在第四。**它的價值不在強弱，在於它擋在路中間。**

8. **荒阪無核心，等於沒有可攻擊的目標。**這是它國力墊底卻不可能被消滅的原因——**你打不掉一個不在任何地方的東西。**偉恩可以被找到、被滲透、被對抗；荒阪不行。
9. **偉恩的根就在聯邦**，使「人質關係」成為雙向共生：偉恩抽手則聯邦崩解，但偉恩也無處可去。
10. **聯邦的法治有一個例外，而那個例外就住在境內。**「不敢執法」比正式豁免更傷——正式豁免可預測，執法失效不可預測。**唯一講法律的地方，法律對唯一該管的對象無效。**這也重新定義了「檯面下摩擦」：那是聯邦無法可用時的替代方案。
11. **三千年足以讓創傷變成地理。**那片海如今對絕大多數人而言就只是海，沒有人意識到自己航行在一道傷口上。
12. **今日正道各門派的部分家底，來自當年打撈自家廢墟。**他們不只繼承了罪，還繼承了贓。
13. **那片海把大道洲切得比地圖上更徹底。**兩塊陸地不只隔海，還隔著一片船難行的海。「聯盟難以團結」至此有了最硬的物理成因。
14. **正道門舊址是遺跡的反面**：一個所有人都知道位置、卻什麼也不剩的地方。它的價值不在裡面有什麼，而在於它擋住了誰。
15. **護航行業補上了「散修靠什麼過活」。**這裡有穩定、高風險高報酬的工作，不需要門派背景，只需要能打。兩岸港城因此是最適合安置低階角色的地方之一。
16. 主航線既非走私通道，代表**走私另有其路**——那條路目前空白。

### 關於正道聯盟（v6 改寫）
17. **聯盟不是宗門同盟，是登記制的保護體系。**成員不限門派，商會與船隊同樣可加入。**人物不必拜入門派也能取得庇護**，甚至可以自己創立組織登記。
18. **道統是門派真正的護城河。**碑衡量的不是資產或規模，而是**能不能造出強者**。商會有錢，錢買不到傳承——這是「財富兌換率在高階處斷裂」的組織版本。
19. **「第一個上碑的非門派組織」是一個從未發生、卻完全合法的歷史性事件。**要達成它，實質上必須讓一個商會**長出自己的道統**——一條橫跨數十年的長線。
20. 制度開放而現實封閉——這個落差本身就是可挖掘的線索。

### 關於世界性質
21. **「依個人／依門派／依地點而異，無統一規則」已出現七次**，可確認為穩定的設計語言：**通則只到勢力層級為止。**五方之上有明確結構，五方之下全是個案。世界給的是框架，不是規則書。
22. 這是一個**沒有法律的世界**（聯邦除外，且聯邦有例外）。全球僅有的兩項硬性制度是正道碑與海捕令。
23. **同一種垂直知識落差在多個層級反覆出現**：山巔人對世人隱瞞、帝國皇室對全國隱瞞。

### 關於世界的斷代
24. **練氣以天地昇華自身，煉體以自身對抗天地。**成道的路一條經過天地、一條不經過，因此天地一壞，只斷了一條。**大帝絕跡而武神仍在，是必然而非巧合。**
25. **煉體體系的地位因此大幅上升**：「兩體系無高低之分」在今日有了新意義——**煉體是唯一走得通的路。**
26. 兩條路的哲學是對立的：大帝**成為規則**，武神**拒絕規則**。戰力相當，姿態相反。

### 關於山巔人
27. **山巔人的隱世，恐怕就是閉關續命。**他們卡在門檻前，壽元卻在流逝——不是超然物外，是**在跟時間賽跑，而且注定會輸**。
28. **他們的動機因此不是權力，而是在死之前成道。世上最了解真相的一群人，同時也是最走投無路的一群人。**
29. 三千年前的飛昇圓滿者理論上仍有極少數在世，且**正在逼近壽元終點**——**知道最多的那幾個人，正在死去。**
30. **真正的世界頂層不在任何組織圖上。**

### 關於武神
31. **他不是憑空出現的。**成道前有出身、有師承、有來歷。
32. **他現身時沒有人認出他。**兩百年來無人找到他的原因是——**沒有人知道自己遇見過他。**
33. **追蹤他是徒勞的**，他的現身理由不在世局裡。**唯一的鑰匙是他在意的事**，而那屬於個人史，散修查得到，帝國查不到。
34. **他是永遠懸著的變數**：他不介入，故均勢成立；他若改變主意，一切重算。

### 關於長壽與權力
35. **長壽者長期在位、持續行動**，有時間執行橫跨數百年的計畫。
36. **這關上了底層最後一扇門。**就算你夠強，位置也不會空出來。
37. **這解釋了世界的停滯感**——不是制度完善，而是做決定的人根本沒換過。
38. **權力不是被奪走的，是被擱置的。**繼任者永遠是代理人，**整個世界的權力都處於借用狀態**。
39. **喚醒是核彈級的選項。**不是沒人能救場，是沒人敢付那個代價。
40. **最高戰力都在洞裡**，世界到處是主人不在卻沒讓位的真空。

### 關於悟道與奪道
41. 「你是什麼人決定了你將來可能悟什麼道」把角色扮演與力量體系直接綁死。
42. **無人能事先偵測他人的道，故壟斷道統只剩一種手段——殺光可能走上去的人。**
43. **「論道」是唯一不流血的奪取途徑。**
44. 奪道的關鍵不是打不打得贏，而是**查不查得出攔路者是誰**。
45. **天絕的道是最徹底的死路**：攔路者是碎片，殺不死也無法論道。

### 關於三千年前的大戰
46. **道德框架完全翻轉。**正道門是加害者，今日的聯盟是加害者遺族抱團三千年的產物。任何人得知此事，動搖的都是整個聯盟的正當性根基。

### 關於武神的身分（v7 新增）
83. **「裴武神」這個叫法本身就是證據**：世人明確知道武神姓裴。她的匿名性完全不靠身分保密，只靠**沒有人預期她會出現在眼前**。

### 關於門派與城市（v7 新增）
87. **「同名」是一個公開的權力標籤**：直屬城的名稱本身就在宣告歸誰。相對地，附屬城**名字裡沒有主人**——從地圖上看不出它跟誰有關係，得問人才知道。
88. **門派在山上、不在城裡**，把修仙勢力與人口中心在物理上分開。門派俯瞰城市但不住在裡面，城市因此保有自己的日常運作邏輯。這與 9.1 相互支撐。
89. **直屬是身分，附屬是合約。**合約會到期、會轉向、會被搶。
90. **正道區底下存在一個大規模的自治城市層。**這是世界上少數不由五方直接治理、又不算無主地的空間——**故事可以在這裡長時間發生而不驚動任何一方**。
91. **「默認不行」是一種恐懼，不是禁令。**阻力與實力無關，與依賴度有關——**一座經濟上不依賴任何門派的附屬城，理論上隨時可以走進那道門。**
92. **「制度開著門、現實走不進去」第二次出現**（另一次為推論 19–20），可視為正道聯盟的結構特徵而非巧合。但兩者成因不同：碑的門是**能力問題**，登記的門是**恐懼問題**。
93. **毀城是「單方面終止合約」的極端案例**，並印證了「聯盟在城市層級不介入」的原則。
94. **記錄還在，只是沒人提。**這使它從「永遠失落的歷史」變成**有門檻的線索**——需要門派典籍或聯盟檔案的接觸權限。
95. **聯盟高層不管事，卻在意名聲。**衝突發生時不介入，事後卻為顏面掩蓋。
96. **自治是有邊界的自治。**城市管自己的內政，頭上仍有一層聯盟的行政歸屬，而壓力正是從那一層下來的。

### 關於天祠與行政區劃（v8 新增）
97. **正道碑是權力名冊，不是榮譽榜。**上碑者即常任理事委員，故聯盟的統治權**由一件無人能操控的器物直接分配**。這是世界上唯一一處權力來源不可被人為干預的地方。
98. **7.2 與 7.9 的矛盾因此消解**：天祠既無強制力，壓迫就不是制度性的，而是**上碑者本身實力的自然延伸**。制度沒說話，但每個人都知道對面是誰。
99. **碑不能被竄改，但可以被隱瞞。**窺天局管理碑的資訊，使聯盟內部的資訊落差有了明確的源頭。
100. **暗影隊是天祠唯一直接掌握的武力**，且不受職掌限制。一個宣稱只能協調與仲裁的機構，握著一把不必說明用途的刀。
101. **州／省無主官，使治權出現斷層**：實際管事的只有郡府與市城兩級，而它們之上是一段空的地理名稱。壓迫因此不沿著行政層級傳遞——**它是直接落下來的**。

### 關於軍事（v9 新增）
102. **聯邦不需要強徵，因為當兵本身就是報酬。**募兵制搭配「服役或長期義務」的修煉准入條件，等於**以修煉權換取兵源**——志願者不是為薪水來的，是為功法來的。
103. **聯邦不把修士隔離成獨立兵種**，而是讓他們同時存在於常規部隊與專責部隊。修士在軍中**既是戰力，也是被管理對象**。
104. **唯一能跨海遠征的勢力，與唯一擋在海路中間的勢力，正好相鄰。**帝國的地緣價值因此不只是通道，也是屏障。
105. **帝國能真正抵擋高階修士的地方只有皇都。**常規部隊對修士無效、秘境屏障僅護皇都周邊——邊陲在軍事上是敞開的，靠的是人，不是體系。
106. **皇室與教會的牽制不是結構性的鎖。**皇室的優勢只是程度上的（教會也有精銳），而這個差距會隨時間變動。

### 關於帝國與聯邦（v10 新增）
107. **帝國不是軍事國家。**軍事排在四項支柱之末，儘管教會武裝規模龐大。整個國家的力量從**皇室的生殖能力**開始計算，這使「皇室成員有限」成為結構性天花板。
108. **排第一的支柱恰恰是最不能擴張的那個。**血脈無法量產、秘境被血脈鎖定——這正是「永遠不會崩潰，也永遠無法壯大」的來源。
109. **聯邦的腐敗是外來的，不是內生的。**執法體系本身沒有爛掉，是被外部勢力買下了一部分。因此**對本國人而言，那條制度化的上升管道仍然是真的**——漏洞開在對外那一面。
110. **「聯邦不敢對偉恩執法」有了具體形式**：不只是高層畏懼，而是**執行層已經有人是對方的**。
111. **無專責監察機構，卻有機構在追查。**追查因此是自發的、非制度化的——**追查者沒有保護傘**。

### 關於武道（v11 新增）
112. **武道是體系中唯一可被無數人共享的道。**其餘萬物之道皆一道一人，唯獨武道不排他——煉體之路因此**在結構上遠比大帝之路寬**：無席位限制，也未被天地損傷斷絕。
113. **這是一個用死亡篩選的頂點。**限制不禁止任何人：快的那條路殺死大多數嘗試者，慢的那條路被壽元耗盡。**世界頂點的供給由勇氣與運氣決定，而非資源或血脈。**
114. **「武神」是唯一名實可能不符的境界。**存在名為武神、戰力卻不及止境的人，於是世人以承認與否構成第二道門檻——**真正的名冊不在碑上，在人心裡。**
115. **裴思涵是戰鬥成道者**，故 2.4 對她完整成立。「神龍大俠」不是虛名，而是她走那條路時留下的痕跡。
116. **能力表現各不相同**，代表遇上一名武神時，**過去的經驗不構成參考**。

### 關於條件、道門與大帝（v12 新增）
117. **這個世界不是停滯，是倒數。**大帝之路終將重開（萬年自行恢復），唯一的問題是誰在那之前抵達。
118. **萬年這個尺度切開了個人與組織。**沒有任何個人等得到自行恢復，但門派與勢力等得到。對山巔人而言修復是唯一的活路，對勢力而言只是加速。
119. **路是公共的，位置是私有的。**修復人人受惠，但席位只有一個——競賽爭的不是有沒有，是先後。
120. **正道聯盟可能是落後的一方。**線索散落處之一是靈魂碎片，而聯邦與荒阪都在「研究」碎片，正道卻選擇「封印」——他們親手把自己那份鎖了起來。
121. **遺跡與傳承是三處線索來源中唯一不需要勢力權限的地方**——無所屬者能觸及真相的唯一途徑。
122. **這是文件中第一次出現「無人能說」的知識。**先前的封鎖都是有人選擇不說；大帝的消散是**知道的人無法說出口**。
123. **大帝稀少不是因為難出，是因為出了會不見。**數十萬年信史中大帝始終稀少，機制在此。
124. **消散前實力不變**，代表一名正在消散的大帝**始終是完整的威脅，直到某天他不再出現**。
125. **全世界對頂點的認知建立在一個溫和的誤解上**：眾人以為那是永生，實際上那是一段極長的告別。
126. **修復條件＝重建道門。**這使「修復」從抽象目標變成一個有明確對象的工程。
127. **天絕的第四份碎片已於戰鬥中湮滅，其道卻仍被佔據**——可見佔道的門檻**不是靈魂的完整性，只是靈魂的存續**。

### 關於掌道與奪道（v13 新增）
128. **「身死道消」與「靈魂尚存故道未釋」不是兩條規則，是同一條規則的兩種結果。**雙向作用斷一端即失道——正道門五帝斷在本體被殺，天絕沒斷是因為靈魂還在。
129. **大帝的結局是回饋給自己執掌的那條道。**凋零之時道身化為養料融入其中，這是文件中唯一一處「死亡即歸還」的機制。
130. **要奪天絕的道，就必須毀盡他的靈魂。**而碎片分別在正道（封印）、聯邦（研究）、荒阪（研究）手上，一份湮滅、一份流落在外——**鑰匙被三個互相敵對的勢力各拿了一把**，這才是那條道三千年無人能碰的真正原因。
131. **現況下確定可行的奪道方式只有殺死本體。**論道那條路是否仍開著，取決於那條傳說中的路能做什麼。
132. **那條路目前是傳說等級。**有傳說、無人證實——一條無所屬者也追得下去的頂級線索。
133. **成帝不是被賜予的，是換來的**，付出的是畢生所學。
134. **成帝的瞬間，就是開始凋零的瞬間。**大帝把自己最精華的部分永久寄存在世界之外，本體從那一刻起便失去滋養。

### 關於雙重登記（v14 新增）
135. **登記合法，行使犯罪。**那張正道身分在聯邦是**有效但不能用**的——它確實讓其他正道成員不攻擊你，可你只要靠它做事，聯邦就辦你。
136. **7.7 出現了地理性的例外。**在大道洲，失去正道身分等於可被自由攻擊；在聯邦境內，聯邦法律仍然保護你。推論 78 至此不只是可行，而是**結構上唯一安全的出口**。
137. **正道在聯邦沒有買通的執行層。**項目 19 已確認腐敗來自偉恩與荒阪的滲透，名單裡沒有正道——**那些案子是真的會被辦的**。
138. **聯邦監控而不查辦，等的是動用庇護的那一刻。**那些門派因此活在一個很特別的狀態裡：沒有犯罪，但隨時可以被結束，而且對方一直在看。
139. **這是兩套秩序唯一直接接觸的介面**：一邊靠法律，一邊靠「誰不會打你」，而它們在同一個門派身上重疊。

### 關於地名（v15 新增）
140. **「絕天海」是一塊沒被抹掉的紀念碑。**它因那場大戰而得名，而世人天天說著這個名字，卻不知道自己在說誰——真相被封鎖了三千年，名字卻一直掛在地圖上。
141. **陸地被切開了，名字沒有。**兩塊大陸仍統稱大道洲——**那份統一的執念殘存在語言裡**，即使地理上早已不成立。
142. **「歐姆尼亞洲」簡稱「歐洲」，正好對上「波希特米亞聯邦」暫定名裡的「歐」。**聯邦的正式名稱可能本來就有現成的來源。
143. **波塞頓半島是五方之中唯一可以用一個地名指出核心的勢力。**秘境屏障只護皇都周邊，於是帝國的要害有明確座標——偉恩藏在境內某處、荒阪根本沒有核心，唯獨帝國指得出來。

### 關於地名（v16 新增）
144. **「神龍大俠」其實是在報出身。**裴思涵來自龍隱城，而她成道前的名號帶著同一個字——**一個從附屬城走出來的人，把城名掛在了自己的名號上**。等她成為武神之後，這個名號就沒人再提了。
145. **樓蘭城的名字只活在檔案裡。**城已被毀、記錄被刻意淡忘，而那份記錄僅存於門派典籍與聯盟檔案——**知道這個名字，本身就是一種權限**。
146. **聯邦的正式名稱與地理脫鉤。**波希特米亞聯邦位於歐姆尼亞洲，但國名不取自陸地——這與帝國（亞特蘭蒂斯洲＝帝國領土集合）恰成對比：**帝國的名字就是它的土地，聯邦的名字不是**。

### 關於天祠的決策（v17 新增）
147. **正道聯盟的核心性格已可確認：它的所有規則都是真的，但沒有一條是靠自己站著的。**制度開著門而現實走不進去（7.4）、壓迫來自實力而非制度（7.9）、表決寫著一致決而實際由派系決定（7.2）——同一個模式第三次出現。
148. **海捕令數十年一次是可行的**：不是十餘人各自獨立同意，而是**主導派系點頭之後其餘跟進**。
149. **每個席位名義上都有否決權，但否決權的實際價值取決於你是誰。**
150. **「大部分時候等於碑上排序」的那個「大部分」很有價值**——碑序低卻位階高的人，是委員會裡最值得注意的異常；他靠的是底蘊、聲望或手段，而那些東西碑量不出來。
151. **委員會規模隨天下實力分布浮動。**無固定名額意味著它理論上可能萎縮到只剩數人，也可能膨脹——**統治集團的大小不由任何人決定**。
152. **「同形不同源」第二次出現**（山巔、羽化）。兩套體系共用漢字詞彙已可視為此世界的常態，而非設計疏漏。

### 關於正道門的真相（v18 新增）
153. **聯盟從不說謊，它只是不說。**樓蘭城如此，正道門的真相亦如此——不銷毀、不否認、只是淡化。同一手法第三次出現，可確認為它面對污點的標準反應。相對地，帝國選擇的是主動改寫：**一個說謊，一個沉默。**
154. **山巔人同時握著兩個秘密**：道門被毀，以及正道門是加害者。他們是這個世界唯一看得見完整因果的人——**而他們正在死去**（推論 29）。
155. **檔案在加害者的直系後裔手上，而他們可能從未打開過。**
156. **「依門派而異」在這裡特別鋒利**：有些原生分支的高層每天在聯盟裡開會，清楚知道自己的來歷；有些則完全不知情，**真心相信「正道」這兩個字**。
157. **兩個秘密的封鎖邏輯截然不同。**道門是競爭——有利可圖，因此會有人主動追查；正道門的真相是羞恥——**沒有人有動機去挖它**。這使後者比前者更難被發現，儘管它的知情門檻其實一樣低。

### 關於碑與席位（v19 新增）
158. **個人被徹底排除在制度之外。**碑只認組織，於是再強的個人也拿不到席位——**裴思涵拿不到，山巔人也拿不到**。這正好解釋了 3.6 已確認的「多成為各方勢力的幕後」：**不是他們選擇躲在後面，是前面沒有他們的位置。**
159. **席位屬於門派，坐在那裡的人只是代理。**這與推論 38「繼任者永遠是代理人，整個世界的權力都處於借用狀態」完全同構，且是它第一次出現在正式制度裡。
160. **「保留席位但不得表決」保有的不是權力，是數月的情報通道。**掉下碑的門派仍坐在那間屋子裡，聽得見全部討論，卻不能出聲。
161. **這是文件中第一次出現「碑說了不算」的地方。**雖然只是時間差，但在一致決之下有實質重量——**一個已經掉下碑的門派，短期內仍佔著一個不能用的位置**。
162. **推論 19 因此更難達成。**商會若要上碑，不只要長出道統，還必須把整個組織的產出能力堆到擠下現有十餘個門派之一——**這不是加入，是取代**。

### 關於聯邦的建國（v20 新增）
163. **聯邦誕生在修士剛剛失去最高上限的那個時間點。**大戰斷了大帝之路，兩百年後一個由凡人與修士共治、以制度切割修士權力的國家出現在另一塊大陸上。兩者是否有因果，目前無解，但時間軸貼得很近。
164. **「聯邦」二字自始就是修辭。**它不是集權化的產物——建國時就選了一個不符合實情的名字，而做這個決定的人有理由。
165. **柏拉圖・斯坦尼在位將近兩千八百年。**9.6 的「權力高度固化」在聯邦不是例外，而是最極端的案例：一個以民選與制度自豪的國家，最高元首從建國第一天起就沒換過人。**選得出來的那個位置，本來就不是最高的那個。**
166. **「境界並沒有成為他們的隔閡」有一個殘酷的下半段——時間成了。**十二人並肩建國，兩千八百年後只剩修士還活著。
167. **國父是凡人，而且已經死了。**活著的修士同伴仍坐在最高的位置上，替一個凡人的理想繼續掌舵——而那個理想本身，就是「境界不該成為隔閡」。
168. **聯邦是革命出身的國家。**它從和平運動起家，最後承認和平運動不夠用——這個經歷可能解釋了它為何比誰都執著於法律與制度。

### 關於荒阪（v21 新增）
169. **荒阪的要害不是地方，是人。**節點可以有很多個、毀一個不影響其他，但領導者只有一個。推論 8「你打不掉一個不在任何地方的東西」仍然成立，只是要補上一句：**它有一個在某個地方的人**。
170. **三方的要害形成完整對照**：偉恩的要害是地方（核心在歐姆尼亞洲境內某處）、帝國的要害是地方且指得出來（波塞頓半島）、**荒阪的要害是一個人**。
171. **這是文件中唯一一個連戰力都無法評估的頂層人物。**武神有明確定位、山巔人層級明確、偉恩與帝國的血脈可以推算——**只有這個人是空白的**，而他掌握著全世界的黑市與情報網。
172. **「家族世襲」與 9.6 恰成對照。**修士世界的權力因長壽而固化、幾乎不更替；荒阪卻是世襲——這意味著它的領導者**會死，而且換過人**。在一個由千年不換的長壽者統治的世界裡，**唯一按凡人尺度流動的頂層權力，出現在最不受法律管轄的那個組織裡**。
173. **「知道有這麼一個人，卻不知道是誰」本身就是一種防禦。**各方無法評估他、無法定位他，也就無法決定要不要動他。

### 關於靈氣科技與資源地理（v22 新增）
174. **「高階壟斷、低階普及」第二次出現。**功法如此（9.3），容器亦然。可確認此世界的資源分配規律是**底層開放、頂層封鎖**——封鎖高階功法的是門派與黑市，封鎖高階容器的是偉恩。
175. **偉恩掐住的不是運輸效率，是高階靈氣能不能離開產地。**低階容器裝不了高品質靈氣，於是高階資源就算開採出來，沒有偉恩的容器就運不走。
176. **管線只有數公里，於是靈脈的價值極高、輻射半徑卻極小。**每座城市都需要一個近在數公里內的來源，或一條穩定的容器補給線——**靈脈的分布就是這個世界城市分布的骨架**。
177. **「佔山即佔靈脈」打通了正道區的地理邏輯。**門派佔的從來不是山，是能源產地；直屬城建在自家靈脈旁，附屬城各自守著別的靈脈。門派與城市的關係因此本質上是**能源與民生的交換**。
178. **絕天海航線是雙向的能源與物資動脈。**靈氣南下、物資北上，而它必須穿過世界上最紊亂的靈氣海域——**最危險的靈氣環境，恰好橫在唯一的靈氣運輸路徑上**。
179. **誰也切不斷那條航線，因為切斷它的人自己也會受損。**但籌碼並不對稱：北方缺物資只是辛苦，**南方缺靈氣則斷了修煉與科技的根**。
180. **聯盟在制度上鬆散，在物質上卻綁得很死。**7.8「三千年僅一次全員一致」講的是意志，而南北之間的相互依賴講的是身體。
181. **容器就是這個世界的油輪，運輸業即能源命脈。**4.4 已確認的船隊與護航行業因此不只是航運業，而是**跨陸塊的能源產業**。

### 關於反修士科技（v23 新增）
182. **反修士科技是聯邦立國的物質基礎。**法律要管得住修士，得先有東西讓修士知道自己管得住——沒有它，五權分立只是紙。
183. **兩條路線各有性格**：無效化是防禦性的（讓對方的力量失去意義），破壞／腐蝕是攻擊性的（削減對方的本錢）。從執法單位的麻痺彈到軍隊的反靈砲，是同一套原理的不同尺度。
184. **它對煉體者無效，但這不致命——因為它本來就不需要有效。**煉體者是單體傷害，常規邏輯對其仍然成立。
185. **推論 25 再次加碼**：煉體不只是唯一還走得通的頂點之路，還是**唯一不受聯邦科技鉗制的路**。
186. **裴思涵是煉體成道的武神，聯邦對她沒有手段。**
187. **玉璞這條線早於羽化成仙。**修士在跨過第二道門檻之前，就已取得城市級破壞範圍——戰略威脅的產生，早於境界上的質變。
188. **聯邦不需要贏過對方的最強者，只需要讓對方的玉璞以上不再是免費的。**這解釋了為何頂尖戰力弱於三方的它仍能維持恐怖平衡。
189. **荒阪同樣持有碎片、同樣在研究，卻沒有做出同等的東西。**碎片只是原料之一，缺的那部分在偉恩與聯邦手上。

### 關於日常科技與資訊（v24 新增）
190. **一般人一輩子碰到的都是最溫和的那一層。**反修士裝備依殺傷性遞減部署，於是街頭執法用的是壓制類，反靈砲一類屬要塞與軍隊級。
191. **裴思涵的匿名有了更精確的形狀。**在一個有網路、身分可查的世界裡，任何人都查得到她的名字與事蹟——**她的匿名不是因為資訊不足，是因為沒人把眼前的人和資料庫裡的名字連起來**。
192. **樓蘭城的記錄「僅存於門派典籍與聯盟檔案」是刻意的離線。**在一個有網路的世界，某些東西不在網上，本身就是一個決定。
193. **正道用人，荒阪用網。**世界有互通的網路，而窺天局選擇以人力情報為主——兩大情報體系因此不在同一個維度上競爭。
194. **資訊可以跨境流動，但每一段都有人把關。**遺跡與傳承是線索的實體入口，網路是另一條。
195. **發展曲線歪斜，是這個世界最重要的質感來源。**某些方面遠比現實先進，某些方面根本沒有對應物——它不是換了能源的現代社會。

## 十三、測量學革命與同盟會源流（v25 匯入）

> 本章處理的問題是：一個由靈氣推動、**最近萬年維持低文明度**（近似文藝復興前）的世界，如何出現科學革命。
> 結論：科學革命確實發生過，起點為**測量學**，時間約在 **4300 年前**，並於 3000 年前的大戰後遭政治性中斷。現代各地的科研成果並非新生，而是該次革命殘存傳承的復原與再發展。

### 13.1 時間軸

| 時點 | 事件 |
|---|---|
| 約 4300 年前 | **天絕證道**，斥力自此出現。丈天尺校準危機爆發，測量學革命起點。 |
| 4300–3000 年前 | 發展期（1300 年），即**天絕擔任大帝的全部時間**。秘密贊助，行會網絡擴散，理論躍遷完成。 |
| 3000 年前 | 大戰。六位大帝俱亡，大道洲分裂，道門被毀。 |
| 3000 年前起 | 行會遭全面政治性打壓，轉入地下。擴散停止，進入保管而非發展的狀態。 |
| 現代 | 大道洲無傳承；他處程度不一，最終促成同盟會成立。 |

### 13.2 革命的前提：四道鎖

萬年停滯並非「無人想到」，而是四項結構性條件同時作用：

1. **不可重複**——靈氣回應資質與心性，同一操作於不同人身上結果不同，只能師徒授受。
2. **不可量測**——僅有「濃」「稀」「精純」等體感描述，無單位。
3. **不公開**——秘傳單線授受，無同行審查，無累積曲線。
4. **不缺乏**——靈氣足用，個體修士遠勝任何機械，無人有動機投資效率。

突破口為**第 2 道鎖**，並連帶解開第 1 道。**計量學先於力學。**

### 13.3 載體：大地綜合行會

- 由堪輿師、木匠、石匠等組成，為**原本即存在的合法同業組織**，組成純屬實務需求。
- 秘密結社為其**內部子組織**，寄生於合法外殼之中。
- **準入看技術，不看修為**，成員兼有無資質者與低階修士——此標準造就**凡修混雜的生活環境**。
- **意識形態**：「**資質不應成為決定世界的方式**」。此主張**由校尺帳簿中自行長出**——量測所證明的是：靈氣是世界的性質，不是人的天賦；它有地點、有分布、有數量，與持有者是誰無關。修士的資質差異因此被重新理解為**取用效率的差異**。
- 它是**資料的結論**，而非煽動的口號，故難以撲滅。

### 13.4 器物：丈天尺

- 原為**工程用測量儀器**，非為測靈氣而造；**已普遍裝備於各行會**；**可複製，無單一原器保管中心**。
- 此三項構成天然掩護：**擴散不需密謀，只需改變用途**。

**材質構成**

| 部件 | 功能 |
|---|---|
| 玉石 | 感應靈氣 |
| 靈木 | 承載靈氣、刻劃刻度 |
| 金屬 | 校準 |

- 三種材料響應速率與方式不同，**同一器物內部即存在讀數分歧**——多變量是理論化的必要條件。

**三材質的性格（v27）**

| 材質 | 性格 | 角色 |
|---|---|---|
| **金屬** | **最穩定** | 適合作為**校準材料** |
| **玉石** | **最靈敏** | 負責**感應** |
| **靈木** | **具有天然刻度** | 最初的「**丈天**」基準，器物之名的由來 |

> 三者各自對應一個階段：**木是起點，玉是感官，金屬是紀律**。一把尺同時裝著這三者，內部的分歧因此是必然的。

**現代狀態**：三者的分歧**已建立模型，可以換算**。此模型完成於大戰中斷之前——否則三千年的帳簿無法互相對照。**結社保管的不只是資料，還有那個模型。**
- **校準因此成為獨立技藝**，校準者為網絡的權力節點。
- 木材確實會受潮變形，此一事實提供了數百年的天然掩護。

**技術發展階段**

- **零代（誤差期）**：各地丈天尺對不齊，長期歸咎於木料與師承。行會有**校尺慣例**，遂有校尺帳簿。第一個突破只需有人將數百年記錄攤開，發現偏差**隨地點而變**——**革命的起點是會計工作，不是靈光一閃**。
- **一代（測方向）**：以重力為免費基準，靈氣密集處使**垂線偏向**。產出為方向而非大小。商業用途立即成立（探脈、選址、判斷礦脈與秘境位置），**擴散靠利潤而非理想**。
- **二代（測大小）**：以擺或天平「對抗」靈氣作用而得數字。單位由既有營造尺度與砝碼制度衍生。
- **三代（跨地比較）**：需要可攜帶、可自校準的器物，並產生原器歸屬問題。

### 13.5 隱喻底座：靈氣為場

垂線偏向密集處，確立靈氣**吸引**物質。由此定下後世語彙：靈氣**有源、有場、有距離衰減、可疊加**。修行的描述因此改變——不再是「吐納」或「感應天地」，而是**進入某個場的作用範圍**。

**附帶推論：修士可被測量。** 修士本人亦是一個源，高階修士行經時附近丈天尺皆會動，**修為首次可被外人讀成數字**。此事由行會主動發現；在修士界中並非新發現（偵查法術早已存在），行會的創見是**量化與機械化**——而這正是山上門派完全看不上的部分。

### 13.6 存活機制

**第一重：宗門的輕視**

宗門的邏輯自洽——偵查法術即時、精確、不需器物。其誤判在於忽略量化的三項價值：

1. 器物讀數**不依賴施術者**，可跨人比較。
2. 讀數**可以留下**，可跨時累積。
3. 器物**可以複製**，可同時於千處測量。

宗門比較的是單次測量的精度，行會積累的是測量的**總量與可比性**。此誤判不需宗門愚蠢，只需其**以自己的標準評價**。

**第二重：天絕大帝的秘密贊助**

- 天絕為當年秘密保護結社的成員**之一**。
- **【v36】偉恩家族亦為保護者之一。**
- 他認為此種對「道」的研究，對他的世界理念與期許具有重大意義。
- **宗門不知行會與天絕的關係。**
- 保護期即為擴散最快的 1300 年，於他戰死之刻結束。

### 13.7 保存形式：千年帳簿

- 校尺帳簿保存**逾千年**，**全球分散，無總帳**。
- 無總帳即**無可攻擊之單點**；代價是同步問題，各地帳簿必須有共通格式與校準基準。
- 此需求賦予秘密結社**實質功能**——它不是理念社團，而是**格式與校準的維護網絡**，理念是附加物。切斷它等同切斷行會的日常營運。
- 分散意味無人能一眼見及全貌，**綜觀成為需要旅行與權限的稀有工作**。能綜觀者自然成為結社核心，也是唯一可能先於任何人察覺「靈氣結構正在改變」的人。
- 保存千年所跨越的不只是地點，而是**時間**——他們握有全世界獨有之物：**靈氣分布的長期變化記錄**。

### 13.8 理論躍遷：天絕之道與全域基準漂移

**天絕之道的性質**
- **概念型之道，內容為排斥、拒絕、否定。**
- 成就大帝後，**被動地**對整個世界產生斥力——斥力為成道的副產品，非主動施放。

**訊號的形狀：全域偏移，而非局部異常**
- 作用均勻覆蓋整個世界，**它不製造異常點，它移動基準本身**。
- 修士的偵查法術做的是相對比較，**均勻的全域項在相對比較中會被完全抵消**。宗門並非疏忽，而是其方法論在原理上看不見此類事物。
- 唯一能見者，是持有絕對讀數且時間基線足夠長的記錄——**千年帳簿**。

**機制：校準危機**
- 因果並非「他們發現了斥力」，而是**他們的校準網絡壞了**。
- 全世界的尺同時偏移，方向一致、幅度幾乎相同——受潮是隨機且地區性的，此次偏差是**一致的**。
- 排除所有儀器故障後，剩下的唯一解釋是：**不是尺變了，是世界變了**。
- 行會被迫走完「分辨隨機誤差與系統誤差」這一步，**動機不是好奇，是生意做不下去了**。

**概念突破：靈氣有正負**
- 既定：靈氣被理解為吸引。新增：出現一個方向相反、且無法歸因於任何具體地點的項。
- 唯一的容納方式是承認靈氣作用**帶有符號**——存在一個與聚集相反的量，它不是「沒有靈氣」，而是「負的靈氣」。
- 至此他們才擁有**理論**，而不只是擁有數據。

**時序上的巧合**：此時他們正好走至二代（由測方向轉向測大小），而均勻斥力項**不會使垂線傾斜，只會改變量值**——訊號精準地打在他們最脆弱的那一代技術上。**方向無誤，大小全錯。**

**天絕的知情程度**：**知情，但不夠清楚**。他知道自己在推動世界，卻不知推動的形狀——因為他的感應同樣是相對的，**他自己就是那個看不見全域項的人**。世上最強的存在，必須依賴一群持木尺的凡人才能知道自己做了什麼。兩者的關係並非保護者與被保護者，而是**唯一的觀測對象與唯一的觀測者**。

> **附註**：他的道是排斥、拒絕、否定，而他所保護的是一群主張「不應以資質決定世界」的人。兩者可視為同一件事的兩面（**否定既有秩序**），亦可視為諷刺——排斥本身正是最徹底的區隔。此線索與他日後同正道門開戰的動機直接相關。

### 13.9 中斷：大戰後的清算

- 他沒落後，**所有行會皆遭強力打壓**，因而轉入地下。
- **宗門不知天絕與行會的關係**，故清算的理由並非「此處藏有危險知識」，而是**行會是天絕親民路線的政治符號**。
- 清算因此是**廣泛但不精確的**——百工百業一同受壓，而藏於校尺帳簿中的東西根本未被辨認。**壓迫者不知自己在找什麼，因此找不到。**
- 此優於精準清算：精準清算會摧毀知識，廣泛清算只是將其壓入更深處，並**使所有受害行業產生共同記憶**。三千年後這份記憶已與測量學無關，但它是現代任何反宗門秩序組織所繼承的**情緒底層**。
- 三千年前失去的不只是一群工匠，而是**一整套「山上與山下可以是同一個世界」的可能性**。
- **技術後果**：公開網絡消失，但校準網絡不能消失，否則帳簿失去可比性。故地下化的核心任務是維持格式與基準的傳承——**清算之後，結社不再是行會的內層，它成了行會唯一剩下的東西**。代價是擴散停止。**【v39 修正】保管期約為五百年**——此後測量學曾一度不再是成長中的學科，而是一份被保管的遺產，直至約 2500 年前開始復興。

### 13.10 現代殘留

**殘餘斥力**
- 斥力**至今仍在持續，但觀測資料顯示正在漸漸減弱**。
- **技術後果**：
  1. **尋碎片的手段**——五片碎片各自為一個殘餘源。既是局部而非全域，它們**會使垂線傾斜**，回到一代技術即可偵測方向。難處在背景雜訊。
  2. **一支世界級的倒數計時**——衰減速率可外推，因而可估算碎片何時完全消散。
  3. **預警機制**——若某片碎片的訊號**變強而非變弱**，代表有人在餵養它，或它正在恢復。
  4. **基準漂移**——所有以「當前」為準的修行經驗與典籍，其實建立在一個移動中的基準上。**此為現代修士無法復現古法的技術性解釋。**

**知識的分布狀態**
- **殘餘斥力衰減一事已是基礎科學常識**，凡進行科研者皆知。
- 知識落差的形狀因此不是「誰知道」，而是「**誰有能力測量**」。**競爭發生在儀器與資料，不在知識本身。**

**現代具備完整測量能力者（v27）**

| 具備 | 不具備 |
|---|---|
| **波希特米亞聯邦**、**偉恩企業**、**荒阪集團**（三方**能力相當**） | **正道聯盟**（清算最徹底，無傳承）、**亞特蘭蒂斯帝國**（另有自身的技術體系，但**缺乏計量基準傳統**，見 10.4） |

- **三方之外仍有獨立機構**：**行會後裔與學術機構**，不隸屬任何勢力。
- **帝國對斥力衰減一事「知道有這回事，但無法驗證」**——它不是無知，是被排除。

**與 6.4 的關係**

| | 斥力衰減 | 道門修復知識 |
|---|---|---|
| 性質 | 公開的科學事實 | 各勢力主動隱瞞的專有資訊 |
| 取得方式 | 儀器與資料 | 遺跡、傳承、檔案 |
| 競爭點 | 測量能力 | 資訊獨佔 |

> 兩者可能在某一點交會（衰減曲線是否與天地損傷相關），但機制不同，應分別處理。

### 13.11 傳承分布與同盟會

- **大道洲：打壓力道最強，因此無傳承。**
- **其他地區：皆出現程度不一的傳承，並產生新的科研成果。**
- **同盟會出自行會，後分化而出**——它並非外部重建的校準網絡，而是**行會裡走出去的那一批**。這一次規模為國際性，且不再需要躲藏（見 10.3）。

> 三千年前那個組織長出了兩樣東西：**一個變成了國家，一個變成了標準。**

**大道洲的結構性弱點**：正道聯盟境內所缺的並非資訊，而是**科研體系**。他們可自外部得知斥力衰減一事，卻**無法自主驗證**。對一個以天祠與窺天局為情報核心的勢力而言這是結構性弱點——其情報能力建立在人與法術之上，而**此事只有儀器讀得到**。

**結構對稱**

| | 大道洲 | 聯邦 |
|---|---|---|
| 三千年前 | 清算最徹底 | 清算未及 |
| 傳承 | 無科研傳承 | 傳承延續 |
| 能力 | 依賴法術與人力情報 | 發展出量測與標準 |
| 制度核心 | 正道碑登錄者（人的排序） | 法律（規則的排序） |

> 兩者的分歧可直接回溯至三千年前的清算力道差異。**聯邦是唯一繼承了「基準」這個概念的地方。**

### 關於測量學革命（v25 新增）
196. **天絕擔任大帝的全部時間，就是行會的保護期。**約 4300 年前證道、3000 年前戰死，整整 1300 年——保護不是他生涯中的一段插曲，**保護期就是他成為大帝的全部時間**。
197. **校準危機讀到的，是一個人成道的瞬間在整個世界留下的痕跡。**不是世界忽然變了，而是世界多了一位大帝。
198. **推論 21 有了歷史成因。**「規則僅適用於勢力層級以上、其下無統一標準」並非世界的天性，而是**三千年前那次融合方案崩潰後的長期後果**——融合失敗，剩下的就是各自為政。
199. **推論 22「唯一有法律的地方是聯邦」也有了成因。**標準化的傳統走到最後就是成文法；聯邦是五方中**唯一由技術網絡演化成政治實體者**，其餘皆由權力或血統起家。
200. **正道聯盟的情報體系有一個原理性的盲區。**窺天局以人力與法術為本，而全域項在相對比較中會被完全抵消——**有些事情它不是沒查到，是它的方法看不見**。
201. **「山上與山下可以是同一個世界」是三千年前真正失去的東西。**七、九兩章所描述的整個階級結構，都是這個方案失敗後的殘骸。
202. **壓迫者不知自己在找什麼，因此找不到。**廣泛而不精確的清算保住了知識，卻在所有受害行業裡種下一份共同記憶——那份記憶今日已與測量學無關，卻是任何反宗門組織的情緒底層。
203. **修士無法復現古法有了技術性解釋**：基準本身一直在移動。
204. **碎片可以被儀器找到。**一代技術即可偵測局部源的方向——這與「遺跡、傳承、檔案」是完全不同的一條尋找路徑，而**大道洲沒有這條路**。

### 關於科技的定位（v26 新增）
205. **科技存在的理由不是讓強者更強，是讓弱者也能過同樣的生活。**這條原則把整個靈氣科技體系與第十三章的意識形態接成一條線——從千年帳簿到今日的家用產品，做的是同一件事：**把因人而異的東西，變成人人可用的東西**。
206. **沒有石油，所以沒有塑膠、沒有內燃機，也沒有二十世紀。**石化空白使這個世界不可能重演現實的工業史，它的「現代」是另一條路走出來的。
207. **電子空白卻有網路**，代表它長出了功能相似、物理基礎完全不同的替代品——**形狀相似，來源無關**。
208. **材料與交通遠超現實，恰好對應 9.7 的能源地理。**管線只有數公里、長程靠容器，於是運輸壓力極大——**這個世界把最多的技術投在了把東西運走這件事上**。
209. **偉恩的壟斷因此落在最要害的兩個領域交界處**：高階容器同時是材料問題與運輸問題。

### 關於測量能力的分布（v27 新增）
210. **五方之中有兩方是瞎的。**正道聯盟因清算最徹底而失去傳承，帝國因從未走上這條路——**而它們正好是唯二以「正統」自居的勢力**。
211. **這是一場三足賽跑。**聯邦、偉恩、荒阪握有同等的眼睛，卻為了不同的目的在看。而三方同時具備發現「碎片訊號變強」的能力，**也就同時具備被對方發現的風險**。
212. **行會後裔與學術機構是最重要的中間層。**它們是三千年前那個網絡最直接的遺體，**不必投靠任何一方就能接觸**——比遺跡更貼近日常。
213. **丈天尺的名字來自靈木的天然刻度。**這把尺最早是用木頭的紋理去丈量天地的，玉與金屬是後來加上去的。
214. **換算模型是中斷前完成的最後一件事。**它使地下化之後的帳簿仍能互相對照——沒有它，三千年的保管會變成三千年的失聯。

### 關於新增地理（v28 新增）
215. **高譚在東岸、華盛頓在西岸。**偉恩的城與聯邦的首都分處大陸兩端——**距離權力中心最遠的那座城，才是真正不受管的地方**。
216. **高譚是「不敢執法」的極致形態。**不是聯邦放棄了某些案子，而是整座城市的司法與行政都是傀儡：**唯一有法律的國家裡，有一座城市的法律屬於一個家族**。
217. **蓬萊與福爾摩沙形成對照。**兩座都在大道洲門口、兩座都不歸正道聯盟管，理由卻完全相反——**一個沒人想管，一個沒人管得了**。
218. **7.7 的真正意思因此浮現**：「不存在獨立生存的選項」講的不是不准獨立，而是**你擋不住**。擋得住的人，規則就管不到他——而全世界目前只有福爾摩沙做到了。
219. **大肚秘境是秘境的另一種用法**：不是藏東西的地方，是**擋人的地方**。
220. **荒阪的節點藏在無主地裡。**蓬萊是自由貿易區，因此荒阪不需要隱藏——**在一個沒有人有權力查你的地方，公開就是最好的掩護**。

### 關於亞特蘭蒂斯（v29 新增）
221. **帝國崇拜的神是真實存在過的人，而且是依照世界規則自然消失的。**它的經典不是神話，是一份數萬年前的訃聞被寫成了教義。
222. **帝國供奉著一個空著的神位，而它自己並不知道那是空的。**海之道已釋出，只是道門已毀，無人走得上去。
223. **這部教義是結構性不可證偽的。**大帝的消散是不可名狀、不可言說之事（3.9），連波賽頓本人都不可能留下說明——**就算有人查到真相，那份知識在原理上無法被完整表述**。
224. **一個信仰建立在「他仍在注視」之上的國家，最不需要的就是測量。**帝國的半鎖國、排外與無科研傳承，至此有了同一個成因。
225. **極少數知情者維護的不是謊言，是一個沒有人能證明也沒有人能推翻的空位。**
226. **帝國起源於一個比它的神更古老的地方。**秘境早於波賽頓存在，其來歷至今無人追問——這是帝國內部最大的一塊空白。
227. **波賽頓極可能是自然走完全程的。**證道於數萬年前，而消散可持續萬年——他不是被殺，是**時間到了**。他是文件中唯一一個確定善終的大帝。
228. **練氣為主，呼應了帝國的戰略定位。**修士是戰略武器（8.4），於是帝國的教會武裝雖規模龐大，其真正的威懾仍來自玉璞以上的修士——**一個嚇阻型而非消耗型的國家**。

### 關於帝國的人文與科技（v30 新增）
229. **在帝國，離首都越遠越像現代世界。**財富與威嚴集中在中心，而與外界的連結集中在最窮的地方——**真正排外的是中心，邊陲早就漏光了**。
230. **神殿與皇宮共構一座核心**，這是政教合一在建築上的直接體現。它們在物理上就分不開，於是能互相牽制，卻不能互相取代。
231. **排外有一部分是物理性的。**水下城區意味著這是一座外人不只是不受歡迎、而且**進不去**的城市。
232. **v26 的原則在最不平等的國家現身。**一個以血脈定貴賤的地方，靠科技讓沒有天賦的人也能住進它的核心——**輔助裝置就是「把因人而異的能力變成人人可用的產品」的實例**。
233. **帝國不是落後的神權國家，是一條走岔了的技術路線。**強於造物，弱於度量：**它做得出東西，卻看不見世界**。
234. **帝國最不願外流的東西，最可能出現在荒阪手上。**科技少量流出，而境外流通的主要管道是黑市與荒阪。
235. **推論 70 得到補強。**帝國的天花板是人數——而能住進核心的，本就只有血脈夠純、或負擔得起裝置的人。

### 關於帝國的社會（v31 新增）
236. **帝國排的不是外國人，是不懂水的人。**它接納擅長水法者——這道門檻與血脈無關、與國籍無關，只與能不能在這裡生活有關。
237. **帝國的排外不在門口，在門內。**你進得來、住得下、用得上他們的城市，卻永遠不是他們的一員——這比純粹的敵視更冷。
238. **偉恩與荒阪的錢進得來，人留不下。**「可經商、不可定居」正好對應 10.4 已確認的邊陲滲透形態。
239. **全世界最不平等的國家，有全世界最普及的修煉基礎。**水法是基本教養，於是 9.1「普通人是經濟結構的產物」在帝國不成立——**那裡的門檻不是錢，是血脈與神授，一條你再努力也跨不過去的線**。
240. **推論 73 有了成因。**邊陲教會的忠誠建立在無知而非利益上——**那不是被灌輸的信仰，是生活本身**。信仰、生計與修煉三者在帝國從未分開過。

### 關於派系結構（v32 新增）
241. **正道聯盟的統治集團實質上就是正道門的遺族。**原生派過半、且普遍排名靠前，其餘四派加起來仍是少數。
242. **一個過半的集團永遠無法主導，一群少數派永遠無法被排除。**一致決不看多數，於是原生派推不動任何事；但任何事沒有原生派點頭也做不成。
243. **委員會裡最大的那個派系，其凝聚力來自一個他們多數人並不理解的歷史。**過半席位的共同身分是加害者的直系後裔，而此事僅山巔人層級知情（6.6）。
244. **北方掌握位階，南方掌握票。**席位數相當而實力北優，在一致決之下正是僵局的完美配方——**南方擋得住，卻推不動**。
245. **被所有人看不起的那一派，握著和別人一樣的否決權。**「以錢入道」在位階上永遠低，在議事上卻不能被繞過。
246. **五派不是五個平行陣營，而是三個能自立、兩個必須選邊。**旁門左道需依附他派，這使派系內部本身就有從屬結構。
247. **三條派系線互相切割。**一個門派可能與北方同鄉、與南方某派道統相近、同時自己是原生分支——**每條議題會激活不同的組合**，這正是「一致決卻無絕對強制力」的實際成因。

### 關於十六門派與七星（v33 新增）
248. **劍道在碑上兩極分化。**攻擊力最強的道統，兩家分踞第 2 與第 16——**這條路要嘛走到很前面，要嘛只是勉強掛著**。
249. **原生派 7 席、其餘 9 席，是比過半更好的力學。**原生派再團結也不是多數，但沒有任何組合能繞過它——加上一致決，形成一種**誰都無法單獨行動**的僵持。
250. **有一家七星宗門至今仍在，只是不在碑上。**它同源、有資歷、可能保有原生分支的機密檔案，卻不在權力桌上——**知道得夠多、資格夠老、但已經出局**。
251. **原生派內部本來就不是鐵板一塊。**核心五家彼此是同源的兄弟，**而他們都記得那場內鬥是怎麼打的**。
252. **北斗少了兩顆星，而這件事寫在所有人的名字上。**任何看得懂星名的人都會發現缺口——**這是文件中最公開的一條線索**。

### 關於道統（v34 新增）
253. **原生派的優勢是實質的，不只是資歷。**它們排名靠前，是因為手上握著那個曾經產出五名大帝的道統——**正道門那條路的正本，就在這七家手上**。
254. **這條道統曾經一口氣送出五個大帝，如今一個也沒有。**不是傳承斷了，是道門毀了（3.8）。**七星宗門守著一條確定走得通、卻無處可去的路**——他們是全世界最接近頂點、也最清楚自己到不了的人。
255. **它們同時繼承了正道門的道統與正道門的罪，而多數人只知道前者。**
256. **專業是後來者的招牌，原生派不需要招牌。**名單愈往下走，門派名字愈說明自己是做什麼的。
257. **粗分類與「無統一標準」相容。**劍、丹、器、卜算、其他——這是習慣上的講法，不是制度上的區分，沒有人規定，但大家都這樣講。

### 關於偉恩（v35 新增）
258. **偉恩出過力，卻沒有進入神話。**聯邦的建國敘事圍繞十二先賢寫成，而偉恩參與過同盟會卻不在其中——這替「兩者關係最親近」與「檯面下摩擦」同時提供了成因：**它們是一起走過來的，但只有一方被記住了**。
259. **當年那批人裡，留下姓名的多半已經死了，留下血脈的那一個沒有名字。**國父是凡人且已逝，在世先賢僅剩修士；而偉恩是一個延續至今的家族。
260. **它不是被排除在神話之外，是自己選擇不進去的。**
261. **偉恩是唯一一個主動製造內部競爭的頂層勢力。**9.6 已確認這個世界的權力因長壽而固化、幾乎不更替——**偉恩的強不來自誰不肯讓位，而來自有人隨時準備取代你**。
262. **兩個血脈勢力走向相反的形狀。**帝國的血脈是保證（強制產出高天賦，人數有限但品質有底），偉恩的血脈只是傾向（基數夠大加上內部篩選）。
263. **偉恩同時握有天賦與資源，這在文件中是獨一份的。**9.1 已確認修煉的真正門檻是經濟，而偉恩兩者兼具。
264. **不指定方向的資質，解釋了偉恩為何修士與武夫兼有。**帝國皇族只能走海，偉恩可以走任何一條路——**包括那條不受反修士科技鉗制的煉體之路**。

### 關於偉恩與大戰（v36 新增）
265. **偉恩知道天絕在做什麼，也知道行會在做什麼。**宗門不知道兩者的關係（13.6），而偉恩身在其中——**它握有三千年前最關鍵的一份記憶**。
266. **沒有參戰的代價，是三千年後沒有原料。**它離得太遠、沒有下場，於是分不到戰利品，也就缺席了往後三千年的碎片賽跑。
267. **偉恩是唯一同時擁有記憶、技術與資本，卻沒有拿到那五塊石頭的一方。**
268. **它守過那群人，最後卻沒有跟他們走。**同盟會是三千年後重新出現的校準網絡（13.11），而偉恩曾是舊網絡的保護者，卻因理念不合拒絕加入新的那一個。
269. **保護網絡的其餘成員至今空白。**天絕已死、行會轉入地下，而偉恩活著——**它可能是唯一還知道當年還有誰的組織**。

### 關於開戰與瑤光宗（v37 新增）
270. **整場大戰的起點是一場資訊不對稱。**六位大帝同歸於盡、大陸裂成兩半、道門被毀——而正道門動手時，只看見了表層。
271. **天絕的道與他的作為分不開。**3.1 已定「你是什麼人，決定了你將來可能悟什麼道」——**他推動融合，正因為他是那個道**。
272. **瑤光宗是文件中最有力的一個空位。**它同時具備四項條件，而其他組織都不齊全：同源、有檔案、不在權力桌上、且沒有人在看它。
273. **它是唯一一個知道真相、卻不受任何政治結構綁住的原生分支。**碑上五家彼此牽制、共享一個多數人不理解的來歷；而瑤光宗**退出了那張桌子，卻帶走了資料**。
274. **同一場內鬥裡，一家被打死，一家自己走了。**七星從此只剩五家在檯面上——**而那五家都清楚當年發生過什麼**。

### 關於增強修士與禁忌研究（v38 新增）
275. **世界默契上不碰的東西，恰好是三個最有能力的勢力都在碰的東西。**荒阪在檯面下、偉恩在更下面、聯邦則有國家機器作掩護。
276. **同一塊材料，兩個相反的方向。**聯邦的碎片研究部分催生了反修士科技（往下壓），荒阪則以碎片撬動道與境界（往上推）。
277. **一位大帝的靈魂殘片，被當成了實驗器材。**
278. **「道與境界的人為干預」是文件中第一個直接威脅悟道體系本身的東西。**3.1、3.4 已定：道不可外部檢測、悟道與一生相關、席位一道一人——若境界可被人為干預，那整套規則就有了被繞過的可能。
279. **它停在正確的位置上**：不是已成型的武器，是一個還沒有人做成、但所有人都不肯放手的方向。
280. **偉恩的隱密是有理由的。**它與聯邦是軍事工業複合體、各持部分機密，而它在做一件聯邦未必知情的事——**檯面下的摩擦，可能比 10.1 所寫的更深**。

### 關於行會與非五方（v39 新增）
281. **這是文件中第一個靠不可或缺、而非靠實力存在的勢力。**沒有戰力、沒有領土，卻沒有人能繞過它——因為所有人的測量、檢驗、計算都得用它的標準。
282. **13.7 那句話走到了終點**：結社真正的功能從來不是理念，是格式與校準的維護——**而三千年後，那份維護工作變成了全世界的公共基礎設施**。
283. **大道洲今天用著清算對象的標準。**它三千年前清算最徹底、至今無科研傳承，卻在量東西、驗貨、算數時使用當年被自己打進地下的那群人留下的格式——**沒有人記得那是誰的東西了**。
284. **復興比聯邦建國晚了三百年。**聯邦不是一建國就扶持行會，是先有國，再有餘力去扶那群人。
285. **偉恩守的是本體，不是分身。**它曾是舊行會的保護者，卻拒絕加入從行會分化出去的同盟會。
286. **「五方」這個說法有一道縫。**非五方地區的總量足以構成一股力量——**只是它永遠不會變成一股力量**。

### 關於天錦門（v40 新增）
287. **偉恩的壟斷有一道縫，而那道縫在大道洲。**世界上確實存在不歸偉恩管的高階儲存介質，掌握在一個碑上排第 14 的門派手裡——只是產量太少，撼動不了供應鏈。
288. **有錢、有獨門技術、有否決權，卻仍要看人臉色。**7.2 已定位階來自門派底蘊、聲望與手段——**錢與技術不在那份清單上**。
289. **做東西的和買東西的一樣沒地位。**「以錢入道」靠錢買修為被歧視，天錦門靠手藝賺錢一樣被歧視——大道洲的位階體系裡，兩者同列旁門。
290. **獨門不外傳，使一件商品成為戰略物資。**任何人都能買，沒有人能複製，於是天錦門在一個看不起它的體系裡，握著所有人都需要的東西。

### 關於世界之外的那條路（v41 新增）
291. **那條路的價值是看見，而不是取得。**可觀測、可互動、不能論道——它給不了權力，只給認識。
292. **這幾乎必然就是通往世界真相的路徑。**世界之外是宇宙運轉的底層邏輯，而唯一能前往卻不能奪道的方式，做的事情正是讓人看見底層。
293. **它是傳說等級，且不受任何勢力控制。**碎片握在三方手裡、道門的修復人人在爭——**唯獨這條路沒有人守著，因為沒有人相信它存在**。

### 關於世界真相（v42 新增）
294. **整份文件的因果被倒了過來。**大帝不是世界的頂點，是世界的燃料；成道不是抵達，是被消耗的開始。
295. **這是他們三千年前的處境重演。**行會當年也是先發現尺對不齊、才理解世界多了一位大帝；這一次他們同樣測到了異常卻讀不懂——**只是這回沒有天絕在背後保護，也沒有人告訴他們要找什麼**。
296. **絕天海不是傷疤，是未來的樣子。**若靈氣紊亂正在普遍增加，那片海就不是三千年前留下的痕跡，而是世界接下來會變成的模樣。
297. **模糊地帶在物理上真的在變大。**8.3 所述「禁忌領域無人明文界定、模糊地帶極大」，如今秘境與禁地正在擴張——**默契管不到的區域，正在自己長大**。
298. **推論 210 的份量整個變了。**正道聯盟與帝國看不見的，不只是碎片與衰減曲線，**是世界正在壞掉這件事本身**。
299. **三千年過去，還有七千年要走。**而退化已經開始——**這是一場世界自己與自己的賽跑**。
300. **混沌現在還只是零星的怪事。**沒有人把它們連起來，因為沒有人知道該連什麼。

### 關於混沌（v43 新增）
301. **這個世界的所有繁華之地，恰好都是混沌最不容易滋長的地方。**門派佔靈脈、城市依靈脈而建——**文明的分布，無意間也是防線的分布**。
302. **沒有人要的地方，正是它先長起來的地方。**4.6 已定無主地的第一種成因是貧瘠偏遠，而那正是混沌生長最快之處。
303. **禁地與秘境陷入了一個自我加速的循環。**混沌讓它們變大，變大的它們又更容易生出混沌。
304. **這是消耗戰，不是決戰。**實體可以被殺死，但源頭不除則再生——**必須一直打下去，直到有人補上那道門**。
305. **混沌是世界上唯一的規則例外。**所有勢力、修士與大帝都活在道的規則裡，唯獨它不是。
306. **「規則失效」讓既有定律成了懸案。**當法術與因果會出錯，「一道一人」「道不可外部檢測」這些鐵律還算不算數，就不再是理所當然的。
307. **它會是這個世界第一個不受道約束、且終將擁有意志的存在。**
